# 涉众型经济犯罪资金分析报告模板

以下为十一章结构的报告模板。每章包含**必须覆盖的内容项**和**写作风格指引**。根据实际数据填入分析结果，措辞和详略可自由调整。

---

## 一、基本情况

### （一）案件背景

简要说明案件线索来源、涉案主体、初步犯罪类型判断。

**必须包含**：
- 线索来源（举报、行政移送、资金监测预警等）
- 涉案公司/组织名称（如有）
- 初步判断的犯罪类型（传销/非法集资/集资诈骗等）
- 分析所依据的数据范围

**写作指引**：用1-2段话概述，语气客观。如"经初步研判，涉案账户交易数据呈现典型的涉众型经济犯罪特征，具体分析如下。"

### （二）涉案账户基本信息

以表格展示涉案账户的基础属性。如提供了**账户信息**辅助表，从此表中获取开户信息。

**涉案账户信息表**（数据来源：账户信息表）：

| 项目 | 内容 |
| --- | --- |
| 客户名称 | {账户开户名称} |
| 涉案账户 | {交易卡号} |
| 证件号码 | {开户人证件号码} |
| 开户时间 | {账号开户时间} |
| 开户银行 | {账号开户银行} |
| 开户网点 | {开户网点} |
| 账户类型 | {账户类型} |
| 账户状态 | {账户状态} |
| 当前余额 | {账户余额} |
| 账户角色 | {归集账户/分配账户/吸金账户/通道账户/返利账户/实控人账户} |

> 涉众型犯罪通常涉及多个账户，**必须逐一列出**所有涉案账户，并标注各账户在犯罪链条中的角色。如有子账户信息，补充子账户结构表。

**写作指引**：先确认数据中涉及几个主体账户，逐一列出并标注角色。开户时间如果集中在某个短时间段，要特别指出。

### （三）交易概况

以表格展示总体交易数据。

| 项目 | 笔数 | 金额（元） | 占比 | 涉及对手账户数 |
| --- | --- | --- | --- | --- |
| 收入 | {收入笔数} | {收入金额} | {收入占比} | {收入对手账户数} |
| 支出 | {支出笔数} | {支出金额} | {支出占比} | {支出对手账户数} |
| 合计 | {总笔数} | {总金额} | 100% | - |

**写作指引**：表格后用1-2句话概括核心发现。如有过滤失败交易，注明数量。

### （四）交易结构特点

用"一是……二是……三是……"的递进结构，归纳3-5个核心特征。

**必须覆盖**：
- 收支比例与平衡特征
- 多对一收入 / 一对多支出特征（传销典型特征）
- 特征金额（入门费/投资款）出现频率
- 现金交易占比
- 日均交易密度
- 余额波动特征
- 交易金额分布特征
- 开户时间集中度

**写作指引**：每个特征点先说数据，再给判断。例如："一是资金呈现明显的'多对一归集、一对多分配'特征。收入端共涉及X个不同对手，其中Y%的交易为不同个人向同一账户转入Z元的固定金额，呈现典型的入门费收取模式。"

## 二、资金交易情况

### （一）总体概况

**必须包含的表格**：
- 年度/月度交易统计表（按时间分列收入/支出的笔数、金额、对手主体数）
- 金额分布表（按金额区间分列收入/支出的笔数）

年度统计表参考格式：

| 年度 | 收入笔数 | 收入金额 | 收入对手数 | 支出笔数 | 支出金额 | 支出对手数 |
| --- | --- | --- | --- | --- | --- | --- |
| 2020 | {数据} | {数据} | {数据} | {数据} | {数据} | {数据} |
| ... | | | | | | |

**写作指引**：关注交易量的增长趋势。涉众犯罪通常呈现初期缓慢→中期爆发→后期收缩的特征。对手主体数的增长反映组织规模扩张。

### （二）特征金额分析

**必须包含**：
- 高频出现的固定金额列表及出现次数
- 这些金额与已知入门费/投资档位的匹配分析
- 特征金额交易的时间分布

| 特征金额（元） | 出现次数 | 占收入笔数比例 | 可能含义 |
| --- | --- | --- | --- |
| {金额} | {次数} | {比例} | {入门费/提成/返利} |

**写作指引**：将特征金额与犯罪模式关联。如"金额2,900元出现87次，5,800元出现43次，8,700元出现21次，上述三个金额恰好呈1:2:3的倍数关系，与聚集型传销中常见的E级、D级、C级入门费体系高度吻合。"

### （三）现金交易情况

如数据中有现金标志，单独分析现金交易。

**必须包含**：
- 现金收入/支出的笔数、金额、占比
- 现金交易的异常特征（如集中在某时段、某金额区间、某网点）
- **现金断链分析**：大额取现后是否有对应的大额存现（物理隔离特征）

**写作指引**：涉众犯罪中现金交易常用于规避资金追踪。重点分析现金存取的时空关联性。

### （四）交易地理分布

如有交易发生地字段，分析交易的地域分布特征。

**写作指引**：涉众犯罪的地域特征非常重要。传销窝点通常集中在特定城市/区域，资金操作也呈现地域集中性。

## 三、账户角色分类

### （一）分类方法说明

说明账户角色分类的依据和方法。

**写作指引**：简要说明"根据各账户的交易特征，将涉案账户分为以下角色类别"。

### （二）归集账户（公共卡/收费卡）

**必须包含**：
- 判定为归集账户的依据（多对一收入模式、特征金额等）
- 该账户的交易概况（收入端对手数、特征金额收入次数等）
- 推测其在犯罪链条中的作用

| 账户 | 户名 | 多对一收入天数 | 特征金额收入次数 | 收入总额 | 推测角色 |
| --- | --- | --- | --- | --- | --- |
| {卡号} | {户名} | {天数} | {次数} | {金额} | {入门费收取/投资款归集} |

### （三）分配账户（提成发放卡）

**必须包含**：
- 判定为分配账户的依据（一对多支出模式、定期发放等）
- 提成发放规律（频率、金额档次、接收人数）
- 推测其在犯罪链条中的作用

### （四）吸金账户/资金池

**必须包含**：
- 判定为吸金账户的依据（收入远大于支出、资金沉淀明显）
- 资金来源分析（来自哪些归集/通道账户）
- 资金去向分析（流向实控人账户的金额）

**资金池详细描述表**：

| 项目 | 数据 |
| --- | --- |
| 资金池账户 | {账户号} / {户名} |
| 总收入金额 | {金额} |
| 总支出金额 | {金额} |
| 净沉淀金额 | {收入-支出} |
| 沉淀率 | {(收入-支出)/收入 × 100%} |
| 来源构成 | 投资人直接转入{占比}%、归集/通道账户转入{占比}%、其他{占比}% |
| 去向构成 | 返利账户{占比}%、实控人{占比}%、业务开支{占比}%、其他{占比}% |
| 日均收入 | {金额} |
| 日均支出 | {金额} |
| 峰值收入日 | {日期}，金额{金额} |
| 余额趋势 | {描述：如"持续增长后急剧下降"} |

**写作指引**：资金池是非吸犯罪的资金枢纽，必须详细描述其资金来源构成和去向构成。如有余额数据，应描述余额随时间的变化趋势（增长→平稳→下降通常对应吸金期→维持期→兑付危机）。

### （五）通道账户/过渡账户

**必须包含**：
- 判定为通道账户的依据（收支平衡、快进快出）
- 在资金链条中承担的过渡作用

### （六）返利账户

**必须包含**：
- 判定为返利账户的依据（大量向不同对手转出、金额与投资额存在比例关系）
- 资金来源分析（来自资金池的金额和比例）

**返利账户详细描述表**：

| 项目 | 数据 |
| --- | --- |
| 返利账户 | {账户号} / {户名} |
| 返利总转出金额 | {金额} |
| 返利总笔数 | {笔数} |
| 返利接收人数 | {人数} |
| 返利频率 | {日返/周返/月返/季返，固定日期描述} |
| 返利金额档位 | {如：500元档{N}人、1000元档{N}人、5000元档{N}人} |
| 估算年化返利率 | {返利总额/对应投资总额 × (365/实际天数) × 100%} |
| 返利覆盖率 | {接收过返利的投资人数/全部投资人数 × 100%} |
| 返利时间趋势 | {描述：如"前期稳定月返，后期逐月递减至断付"} |

**写作指引**：返利账户是证明非吸犯罪"以高额回报为诱饵"的关键证据。必须通过返利金额档位推断对应投资档位，通过返利率判断是否属于"明显超出正常收益水平"。返利覆盖率和时间趋势可判断案发前是否已出现兑付危机。

### （七）实控人个人账户

如可识别，分析实控人账户的资金来源和使用去向。

**写作指引**：每类账户用独立小节展示，不要简单列表。要说明分类依据和该账户在犯罪链条中的位置。如果某类账户不存在或无法识别，简要说明原因。

### （一）来源集中度

- 收入端涉及的对手账户总数
- TOP1 / TOP3 / TOP5 占总收入的百分比
- 集中度判断

| 序号 | 对手账户 | 对手户名 | 对手证件号 | 交易笔数 | 合计金额（元） | 平均单笔（元） | 特征标注 |
| --- | --- | --- | --- | --- | --- | --- | --- |

### （三）入门费/投资款来源分析

**必须包含**（如存在特征金额）：
- 向主体账户转入特征金额的对手总数
- 这些对手的身份特征（是否集中来自某地区、某单位）
- 入门费收取的时间分布（是否集中在某个时期）
- 推算的参与人数和入门费总额

**写作指引**：这是涉众犯罪报告的核心章节之一。要通过入门费的来源分析，推断底层参与人员规模。

### （四）重点来源账户分析

对TOP3-5来源逐个分析，关注：交易频率、金额特征、时间分布、人员背景、是否属于某类角色账户。

**写作指引**：资金用途分类是判断犯罪性质（非法吸存 vs 集资诈骗）的核心依据。如"个人挥霍+购置资产"占比远大于"运营开支"，且"还本付息"主要来源于新投资人资金，则倾向认定为集资诈骗（以非法占有为目的）。如有一定比例的运营开支且存在真实业务，则可能认定为非法吸收公众存款。

## 八、可疑点分析

逐项列出每个可疑特征，每项包含：具体数据 + 与阈值的对比 + 结论判断。

**建议格式**："一是{可疑特征名}。{具体数据描述}，{与阈值比较}，{判断结论}。"

**必须覆盖的可疑特征**（根据数据实际情况筛选，至少包含8项以上）：

1. 入门费特征值集中出现
2. 多对一资金归集特征显著
3. 一对多定期发放提成/返利
4. 收支高度平衡或严重不平衡（取决于账户角色）
5. 现金交易占比异常（物理隔离嫌疑）
6. 资金来源/去向高度集中
7. 定额交易占比异常
8. 快进快出特征明显
9. 多账户共享设备（IP/MAC）
10. 对手地域高度集中
11. 对手开户银行高度集中
12. 开户时间集中（有组织开户嫌疑）
13. 涉众关键词交易（入门费/会员费/提成/返利等）
14. 资金大量沉淀在少数账户
15. 流向个人消费/购房/购车的异常资金

**写作指引**：数据说话，先摆事实再下结论。无数据支撑的特征不要硬写。

## 九、犯罪模式与资金穿透研判

### （一）犯罪模式判定

基于前八章的发现，匹配犯罪模式（见SKILL.md中的犯罪模式识别规则），给出明确的犯罪类型判定。

**必须包含**：
- 匹配到的犯罪类型及依据
- 该类犯罪的典型运作模式描述
- 本案的具体运作模式描述

**离线分析限制说明**（必须包含）：
> 本报告基于交易数据的离线分析得出结论，未能结合股权穿透信息（如涉案公司工商信息、关联企业、实际控制人等）及互联网舆情信息（如投诉、媒体报道等）进行综合判断。关于涉案主体是否存在非法吸收公众存款的事实认定，建议结合以下外部信息补充核实：（1）涉案公司及关联公司的股权架构和实际控制人信息；（2）涉案平台/公司的互联网舆情和公众投诉情况；（3）涉案人员的行政处罚和司法记录；（4）涉案产品/项目的真实性验证。

### （二）资金层级模型

根据犯罪类型，用对应的层级模型描述：

**传销类**：
1. **入门费归集层**：描述入门费如何从底层参与人流向公共卡
2. **提成分配层**：描述提成如何按层级逐级发放
3. **资金沉淀层**：描述扣除提成后的净利润如何沉淀
4. **变现层**：描述实控人如何变现获利

**非法集资类**：
1. **集资层**：描述投资人如何将资金投入
2. **归集层**：描述资金如何逐级归集到总部
3. **返利层**：描述如何向投资人返还收益（庞氏结构）
4. **挥霍/沉淀层**：描述实控人如何使用沉淀资金

**写作指引**：结合具体交易数据描述每一层，避免空泛概括。

### （三）涉案资金穿透

**必须包含**：
- 资金从底层到顶层的完整链条
- 每一层级间的资金流转金额
- 估算涉案资金总规模

以资金流向链条形式展示：
```
底层参与人 →[入门费]→ 归集账户 → 通道账户 → 吸金账户 → 实控人账户 → 变现
                 ↑                                   ↓
                 └──────────[提成/返利]───────────────┘
```

**写作指引**：如数据不包含对手的完整交易记录，只做一层穿透并注明限制。

### （四）非吸资金链路闭环分析

**必须包含**：
- 用真实账户和金额举例说明至少2-3条完整的资金闭环链路
- 每条链路标注：起点（疑似投资人）→ 中间环节（归集/通道/资金池）→ 终点（返利回到投资人或资金挥霍）
- 闭环链路的统计汇总：涉及多少投资人存在资金回流、回流总金额、平均回流比例

**举例格式**（用实际数据替换）：

> **闭环链路1**：疑似投资人张某(6222\*\*\*\*1234) →[投资款50,000元]→ 资金池账户A公司(6217\*\*\*\*5678) →[返利发放]→ 返利账户李某(6228\*\*\*\*9012) →[返利3,500元]→ 疑似投资人张某(6222\*\*\*\*1234)。该链路显示张某投入50,000元后通过返利账户回流3,500元，回流比例7.0%。
>
> **闭环链路2**：新投资人孙某(6222\*\*\*\*6789) →[投资款200,000元]→ 资金池账户A公司(6217\*\*\*\*5678) →[还本付息150,000元]→ 老投资人周某(6222\*\*\*\*0123)。该链路呈现典型庞氏特征：新投资人资金直接用于偿还老投资人本息。

**可视化图要求**：
- 生成资金链路闭环有向图（可使用 Mermaid 或 ASCII 文本图）
- 节点用不同颜色标注角色（红色=资金池、蓝色=投资人、绿色=返利账户、橙色=归集/通道、紫色=实控人）
- 边标注资金流向和金额
- 闭环路径加粗标注

**写作指引**：闭环分析是非吸案件的核心证据之一。通过具体的账户和金额举例，直观展示"吸收资金→资金池运作→返利回流"的完整闭合路径，使报告读者能够清晰理解资金运转机制。

## 格式规范

1. **报告标题**：`{涉案主体名称}涉众型经济犯罪资金分析报告` 或 `{账户号}资金分析报告`
2. **数值格式**：金额保留2位小数并加千分位（如 1,234,567.89 元），百分比保留1-2位小数
3. **表格**：重要数据必须以表格展示，不要纯文字堆砌
4. **章节编号**：使用"一、二、三……"作为一级标题，"（一）（二）（三）……"作为二级标题
5. **段落结构**：分析类段落采用"一是……二是……三是……"的递进结构
6. **语言风格**：正式、客观、专业。使用"涉案账户""涉案组织"而非"这个账户""该传销组织"
7. **数据缺失说明**：如因数据字段缺失而跳过某项分析，必须在对应位置注明原因
8. **层级图**：层级架构和资金流向尽量用结构化的文字或ASCII图表展示
9. **敏感信息处理**：账户号、证件号在报告中适当脱敏（保留前4后4位）
