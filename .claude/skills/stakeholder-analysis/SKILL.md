# 涉众型经济犯罪资金分析
## 数据处理要求（强制）

执行本技能前，先使用 `excelcli-analysis` 完成文件导入、字段识别、标准化、筛选和基础统计。银行流水统一分析 `bank_transactions`；涉税数据统一分析 `tax_invoices`、`seller_invoice`、`buyer_invoice`、`tax_registrations` 等标准表。

本技能只规定查案思路、指标体系、模式识别、报告结构和调证建议；不要在技能中提供自定义代码示例，也不要指导智能体自行读取 Excel/CSV 或自建入库流程。


涉众型经济犯罪（传销、非法集资）资金分析的完整方法论。本技能提供分析框架、领域知识、判断规则和分析框架和报告要求，帮助你完成从数据探查到报告撰写的全流程。

## 适用犯罪类型

- **聚集型传销**：以"入门费"为核心，层级分明，收取入门费→发放提成→逐级上交
- **网络传销**：依托APP/网站平台，会员购买虚拟产品/服务，静态收益+动态收益
- **非法吸收公众存款**：以高额回报为诱饵，向社会不特定公众吸收资金
- **集资诈骗**：虚构投资项目或道具商品，以非法占有为目的骗取集资款
- **养老领域非法集资**：针对中老年群体，以养老服务、健康产品为名吸收资金
- **网络商城返利型**：以购物返消费币/积分为名，本质是资金池运作
- **涉诈投资平台**：搭建虚假投资交易平台，以"消费成商""二次增值"等模式诈骗
- **虚拟币传销/跑分**：利用虚拟货币进行资金转移和层级分配

## 数据文件说明

涉众型犯罪资金分析的数据可能包含以下文件（文件名可能不同，以实际列名为准）：

### 1. 交易明细（主表）

核心数据文件，每条记录为一笔交易，包含收付双方完整信息。所有分析的主要数据来源。

**标准字段**：交易卡号、交易账号、交易户名、交易证件号、交易时间、交易金额、交易余额、收付标志（进/出）、交易对手账卡号、对手户名、对手证件号、对手开户银行、摘要说明、交易币种、交易网点名称、交易发生地、交易是否成功、传票号、IP地址、MAC地址、对手交易余额、交易流水号、凭证号、交易柜员号、现金标志、备注

### 2. 人员信息（辅助表）

涉案客户的身份和背景信息，用于补充对手身份背景、工作单位等。

**标准字段**：客户名称、证照类型、证照号码、单位地址、单位电话、工作单位、邮箱地址、代办人姓名、代办人证件类型、代办人证件号码、国税纳税号、地税纳税号、法人代表、客户工商执照号码

### 3. 账户信息（辅助表）

涉案账户的开户属性和状态信息，用于报告"账户基本信息"章节。

**标准字段**：账户开户名称、开户人证件号码、交易卡号、交易账号、账号开户时间、账户余额、币种、开户网点代码、开户网点、账户状态、账户类型、账号开户银行

### 4. 子账户信息（辅助表）

涉案账户的子产品/子类别信息，用于展示账户的完整资金结构。

**标准字段**：银行名称、开户账号、子账户账号、余额、可用余额、子账户类别、币种、钞汇标识、账户状态

### 5. 平台后台数据（如有）

传销或非法集资平台的会员数据，含会员ID、上下线关系、注册时间、层级等。此类数据不一定提供，如有则可极大助力层级架构分析。

**可能字段**：会员ID、会员姓名、手机号、银行卡号、注册时间、推荐人ID、所在层级、充值金额、提现金额、累计收益

> **文件匹配原则**：用户提供的文件可能名称不同，但通过列名可以识别文件类型。优先匹配交易明细，再通过"交易卡号/交易户名/证照号码"等关键字段关联辅助表。

## 分析框架

分析分为五个阶段，按顺序执行。每个阶段完成后检查产出是否齐全再进入下一阶段。

### 阶段A：数据探查与交易画像

**目标**：了解账户全貌，建立基础数据认知，初步判断犯罪类型。

**操作**：读取数据文件，确认列名和数据格式，然后计算以下指标。

**首先检查账户数量**：读取交易明细后，先统计"交易卡号"列的唯一值数量，确认数据中涉及几个主体账户。涉众型犯罪通常涉及多个账户，需在报告开头列出所有涉案账户及其角色分类。

**数据预处理**：
1. 过滤失败交易：如"交易是否成功"列存在，仅保留值为1（成功）的记录
2. **交易明细去重**：银行导出数据中常存在重复记录（如同一笔交易因系统原因重复导出、多表合并时重复等）。去重策略：
   - 首先根据"交易流水号"或"凭证号"去重（如存在该字段且非空），这是最可靠的唯一标识
   - 如无流水号，则根据"交易时间+交易金额+交易对手账卡号+收付标志"组合去重
   - 去重前后记录数对比要打印输出，以确认去重影响范围
   - 去重后的数据才用于后续所有分析
2. 交易时间、金额、方向等字段由 `excelcli normalize` 标准化；如结果异常，先用 `excelcli inspect` 和 `import_issues` 核查字段映射
4. 收付方向通常在"收付标志"列，值为"进"/"出"，先确认具体取值
- 使用 `excelcli inspect "./output/analysis.db" --json --sample 3` 查看真实列名和样例数据。
6. 关联辅助表：通过"交易卡号"或"交易户名"关联账户信息和人员信息

**必须产出的指标**：
- 涉及主体账户数量及各账户角色初步判断
- 交易笔数、交易总额、时间跨度（首尾日期和天数）
- 收入/支出分别的笔数和金额
- 收支平衡度（差额/总额）
- 年度/月度交易趋势（按时间分组的进出笔数、金额、对手主体数）
- 金额分布（按 0-1千/1千-5千/5千-1万/1万-5万/5万-10万/10万-50万/50万以上 共7个区间）
- **入门费特征值识别**：统计高频出现的交易金额值（如2900、5800、8700、69800等传销入门费常见金额），识别可能的入门费档位
- 现金交易笔数、金额、占比（如数据中有"现金标志"列）
- 余额特征：最高/最低/平均/最终余额
- 日均交易笔数
- 交易地理分布（如有交易发生地字段）
- 对手开户银行分布
- 账户开户信息汇总
- **开户时间分析**：各涉案账户的开户时间分布，是否存在集中开户特征

### 阶段B：账户角色分类与资金来源去向分析

**目标**：识别核心交易对手，将涉案账户按功能角色分类，刻画资金流向模式。

**子任务B1 — 账户角色分类**：

涉众型犯罪中，账户通常承担不同角色。根据交易特征将账户分类：

1. **公共卡/收费卡（归集账户）**：特定时间内以"多对一"方式收入现金或转账，用于收取入门费或投资款。判断标准：
   - 收入端存在大量来自不同对手的小额/定额转入
   - 转入金额呈现特征值（如均为2900、5800、69800等固定金额或其倍数）
   - 转入对手数量多且分散

2. **发放提成卡（分配账户）**：特定时间内以"一对多"方式发放工资/提成。判断标准：
   - 支出端存在大量向不同对手的定期定额转出
   - 摘要中含"工资""提成""奖金""分红"等关键词
   - 转出金额有规律性（如每月固定日期发放）

3. **吸金账户/资金池**：大额资金最终汇集的账户，是非吸犯罪的资金枢纽。判断标准：
   - 收入金额远大于支出金额（呈现资金沉淀），沉淀率（(收入-支出)/收入）通常 > 30%
   - 来源多为归集账户或通道账户，来源对手数多且分散
   - 可能为对公账户（以公司名义开户），或实控人名下的大额个人账户
   - **资金池的量化描述要求**：必须在报告中明确列出以下信息：
     - 资金池总收入金额、总支出金额、净沉淀金额
     - 资金池的资金来源构成：来自投资人直接转入占比、来自归集/通道账户转入占比、来自其他来源占比
     - 资金池的资金去向构成：流向返利账户占比、流向实控人占比、流向业务开支占比、其他支出占比
     - 资金池的运转周期：日均进出额、峰值进出日及金额
     - 资金池余额变化趋势：是否呈现持续增长（吸金期）→ 平稳 → 急剧下降（兑付危机/跑路）的典型曲线

4. **通道账户/过渡账户**：资金快速过境的中转账户。判断标准：
   - 收支高度平衡（平衡度 < 5%）
   - 快进快出特征明显
   - 单笔金额较大

5. **返利账户**：向下游投资人/会员返还收益的账户，是维持非吸骗局运转的关键环节。判断标准：
   - 支出端大量向不同对手转出，转出对手与投资人群体高度重合
   - 金额与入门费/投资款存在比例关系（如投资10万月返利5000元，即月返利率5%）
   - 摘要含"返利""回报""收益""利息""分红"等关键词
   - 资金来源主要为资金池账户转入
   - **返利账户的量化描述要求**：必须在报告中明确列出以下信息：
     - 返利账户总转出金额、返利笔数、涉及返利接收人数
     - 返利金额档位分布：各档位金额范围、笔数、接收人数（可推断对应投资档位）
     - 返利频率：日返/周返/月返/季返，以及返利日期是否有固定规律（如每月15日、每月底等）
     - 返利率估算：返利总额与对应投资总额的比值，年化返利率
     - 返利覆盖率：接收过返利的投资人占全部投资人的比例（判断是否已出现断付）
     - 返利时间趋势：返利金额/笔数是否随时间呈现递减趋势（提示兑付危机）

6. **实控人个人账户**：传销头目或非法集资实控人的私人账户。判断标准：
   - 接收来自资金池/吸金账户的大额转入
   - 支出用途为消费、购房、购车等
   - 账户持有人与公司法人/股东有关联

**子任务B2 — 资金来源去向分析**：

**必须产出的指标**：
- 收入端涉及多少个不同对手账户
- 支出端涉及多少个不同对手账户
- TOP10资金来源表：对手账户、对手户名、对手证件号、交易笔数、总金额、平均单笔、特征标注
- TOP10资金去向表：同上
- 资金来源集中度：TOP1/TOP3/TOP5占总收入的百分比
- 资金去向集中度：TOP1/TOP3/TOP5占总支出的百分比
- 同名账户识别：对手户名与主体账户户名相同的账户列表及合计金额
- 双向交易对手：既有收入又有支出的对手账户
- 自身转账：对手账户号等于主体账户号的交易统计
- **特征金额对手统计**：向主体账户转入特征金额（入门费档位）的对手列表
- **定期定额转出对手**：从主体账户定期接收相同金额转出的对手列表（疑似提成接收人）

### 阶段C：层级架构与团伙分析

**目标**：通过资金流向、设备信息、地域关联等多维度识别传销层级和团伙网络。

**子任务C1 — 基于资金流向的层级推断**：

这是涉众犯罪分析的核心环节。通过资金流向逐级推断上下线关系：

1. **从底层投资人向上追溯**：已知投资人的交易流水中，投资款流入的对手账户即为其上级账户
2. **迭代挖掘吸金账户**：
   - 调取已知投资者的交易流水，获取投资款流入账户
   - 碰撞多个投资者的交易流水，发现共同转款对象（公共收款账户）
   - 再调取二级账户的流水，继续向上追溯，直到发现最终资金沉淀的吸金账户
3. **入门费/投资款特征匹配**：
   - 根据阶段A识别的特征金额值，筛选所有包含此金额的交易
   - 收取特征金额的账户很可能是公共卡，其持有人可能是寝室长或业务员
   - 特征金额的倍数交易可能代表批量收取入门费
4. **提成发放规律分析**：
   - 识别定期（如每月固定日期）向多人发放固定金额的账户
   - 发放金额的层次差异反映层级：金额大→高层级，金额小→低层级
   - 发放提成的来源、金额、次数确定层级关系
5. **合并分析发现实际获利人**：
   - 将所有吸金账户的流水合并，找出资金转出金额最大的对手
   - 结合金额排序，前几位很可能是实际控制人或高层级人员
   - 注意甄别：资金转出靠前但既非会员又非获利人的账户，可能是平台技术维护方

**子任务C2 — 基于设备信息的团伙划分**：

1. 从交易明细中提取IP/MAC地址
2. 在出账方向上共享同一IP/MAC的账户归为同一操作团伙
3. 使用 Union-Find 算法聚类
4. 输出每个团伙的成员、共享IP数、共享MAC数、与主体账户的交易金额
5. **窝点定位辅助**：网银登录IP可辅助推断操作地点，同一IP下的多个账户操作可能提示作案窝点

**子任务C3 — 基于对手证件号前6位的地域聚合**：

1. 提取对手证件号前6位（户籍所在地区划代码）
2. 相同前6位的对手归为同一地域团伙
3. 涉众犯罪中地域集中性极为常见（老乡传销、同地域拉人头）
4. 结合人员信息表的工作单位/单位地址交叉验证

**子任务C4 — 基于对手开户银行的聚类分析**：

1. 统计每个开户银行涉及的对手账户数和交易金额
2. 大量对手集中在同一银行/网点开户，提示有组织的集中开户行为
3. 在传销中，新入会成员常被要求在指定银行开户

**子任务C5 — 基于交易关系的团伙拓展**：

1. 同名账户关联：不同账户号但户名相同，视为同一人控制
2. **共同交易对手分析**：多个账户与相同对手有交易，提示存在组织关联
3. 稳定资金关系：高频次、大金额的固定交易对手
4. 交易关键词关联：摘要中含"入门费""会员费""服务费""培训费""解债""易物"等关键词
5. 关联人员信息：通过证件号匹配人员信息表，分析工作单位是否集中在同一公司

**子任务C6 — 现金断链修复**（如有冠字号数据）：

传销犯罪中常通过存取现方式进行资金物理隔离：
1. 下级成员取现→上级成员存现，形成资金断链
2. 如有冠字号数据，重点比对存取现时间在同一天、交易柜台在同一城市的记录
3. 通过冠字号匹配修复断链，打通层级间的资金关联

**数据缺失处理**：
- 如果没有IP/MAC列：跳过C2
- 如果没有对手证件号列：跳过C3
- 如果没有冠字号数据：跳过C6
- 不要因为部分数据缺失而放弃整个层级分析

### 阶段D：可疑特征量化与犯罪模式研判

**目标**：对前三阶段的发现进行量化评估，匹配犯罪模式，形成结论。

计算以下可疑指标（详见下方"可疑指标阈值"），逐项给出数值和判定结论。完成后根据指标组合匹配"犯罪模式识别规则"。

### 阶段E：层级架构绘制与涉案规模估算

**目标**：综合前四阶段的发现，绘制完整的层级架构关系，估算涉案规模。

1. **层级架构图绘制**：
   - 基于资金流向的上下线关系，绘制"金字塔型"层级架构
   - 标注每层级人数、涉案金额、角色分工
   - 对关键人员（组织者、领导者、财务、技术等）做特别标注

2. **疑似投资人群体画像分析**（基于交易对手证件号）：

   通过收入端交易对手的证件号码（身份证号）进行投资人群体画像，这是量化涉案规模和受害群体特征的关键分析。

   **总人数统计**：
   - 统计向涉案账户（资金池/归集账户）转入资金的不同对手证件号数量（去重后）
   - 区分"有证件号的投资人数"和"无证件号但有户名的投资人数"，合计得出总人数下限估计
   - 如同一证件号对应多个账户，按证件号合并计算

   **地域分布分析**（基于身份证号前6位行政区划代码）：
   - 提取所有疑似投资人证件号前6位，映射为省份/地市
   - 统计各省份/地市的投资人数量和投资金额
   - 计算TOP5地域的投资人占比，分析是否存在地域集中性
   - 如集中在特定地区，结合涉案公司注册地/经营地分析原因

   **年龄结构分析**（基于身份证号第7-14位出生日期）：
   - 从18位身份证号提取出生年月日，计算年龄
   - 按年龄段分组统计：18-30岁、31-40岁、41-50岁、51-60岁、60岁以上
   - 各年龄段的投资人数、投资总额、人均投资额
   - 判断是否存在特定年龄群体集中受害（如养老类非吸中老年占比通常 > 60%）
   - **性别分布**：基于身份证号第17位奇偶性判断性别（奇数=男，偶数=女），统计男女比例

3. **涉案规模估算**：
   - 估算参与人数：根据入门费特征金额和收款次数推算
   - 估算涉案金额：区分投资款总额、返利总额、实际获利金额
   - 估算层级数：根据资金流转层数和提成级差推算

3. **资金四流分析**：
   - 资金归集流：投资款如何从底层流向上层
   - 资金返利流：提成/收益如何从上层发放到下层
   - 资金沉淀流：多少资金沉淀在吸金账户/资金池
   - 资金变现流：实控人如何将沉淀资金变现（消费、购房、购车、购汇等）

5. **非吸资金实际用途分类**：

   对资金池/吸金账户的支出端进行用途分类，量化每种用途的资金规模。这是判断"非法占有目的"和"资金去向"的关键依据。

   **用途分类标准**（基于交易摘要关键词 + 对手特征 + 金额模式综合判断）：

   | 用途类别 | 识别方法 | 举例 |
   | --- | --- | --- |
   | **还本付息** | 支出对手为已知投资人（与收入端对手重合）；摘要含"利息""返利""本金""还款""兑付"；金额与投资额存在固定比例关系 | 向张某返还月息5,000元 |
   | **业务提成/佣金** | 支出呈定期定额发放模式；摘要含"工资""提成""佣金""奖金""分红""绩效"；接收人为业务员/团队长等 | 每月15日向业务员发放提成 |
   | **个人挥霍** | 流向实控人关联个人账户后用于消费；摘要含"消费""购物""餐饮""旅游""娱乐"；对手为商户/个人消费类 | 实控人转账至个人卡后刷卡消费 |
   | **购置资产** | 大额单笔转向房产/汽车销售公司或个人；摘要含"购房""购车""房款""车款""首付"；对手为房地产/4S店对公账户 | 向某房地产公司转账购房款200万元 |
   | **运营开支** | 转向租赁、物业、广告、技术服务等公司；摘要含"房租""物业""广告""技术服务""平台维护" | 每月支付办公场所租金 |
   | **关联公司转账** | 转向股权关联或实控人关联的其他公司；同一实控人/法人名下的多家公司间转账 | 向关联公司B转账用于资金腾挪 |
   | **其他/不明** | 无法归入上述类别的支出 | — |

   **分类输出要求**：
   - 必须给出各用途类别的资金总额、占支出总额的百分比、交易笔数
   - 以表格和饼图形式展示各用途的占比
   - 重点分析"还本付息"占比（判断是否为庞氏骗局）和"个人挥霍+购置资产"占比（判断非法占有目的）

4. **非吸资金链路闭环分析与可视化**：

   非法吸收公众存款的资金链路通常呈现"闭环"特征，即资金从投资人流出后经过多个中间环节最终部分回流至投资人（以返利形式）。必须用具体的账户名称和金额举例说明完整链路。

   **典型闭环链路举例**：
   闭环示例：
   > 闭环1：投资归集→资金池→返利回流
   疑似投资人张某(6222****1234) --[投资款50,000元]-→ 资金池账户A公司(6217****5678)
   --[返利发放]-→ 返利账户李某(6228****9012) --[返利3,500元]-→ 疑似投资人张某(6222****1234)
   >
   > 闭环2：多层中转→资金池→提成分配→返利
   疑似投资人王某(6222****3456) --[投资款100,000元]-→ 归集账户赵某(6215****7890)
   --[归集转入80,000元]-→ 资金池账户A公司(6217****5678)
   --[提成发放5,000元]-→ 业务员钱某(6228****2345) 
   --[返利发放8,000元]-→ 返利账户李某(6228****9012) --[返利8,000元]-→ 疑似投资人王某(6222****3456)
   >
   > 闭环3：新投资人资金→还旧投资人本息（庞氏特征）
   新投资人孙某(6222****6789) --[投资款200,000元]-→ 资金池账户A公司(6217****5678)
   --[还本付息150,000元]-→ 老投资人周某(6222****0123)

   **可视化图生成要求**：
   - 使用 `excelcli query` 输出链路明细；如需可视化，按账户节点和交易边描述有向资金链路
   - 节点表示账户（标注户名和角色），边表示资金流向（标注金额）
   - 用不同颜色区分节点角色：红色=资金池，蓝色=疑似投资人，绿色=返利账户，橙色=归集/通道账户，紫色=实控人
   - 闭环路径用加粗或虚线标注
   - 生成图片保存并在报告中引用

## 可疑指标与阈值

以下是涉众型犯罪分析的核心可疑指标。分析时逐项计算，每项给出具体数值和判定结论。

| 序号 | 指标名称 | 计算方法 | 正常范围 | 异常阈值 | 高度异常 |
| --- | --- | --- | --- | --- | --- |
| 1 | 收支平衡度 | abs(收入-支出) / (收入+支出) | > 20% | < 10% | < 3% |
| 2 | 入门费特征值命中率 | 含特征金额的交易笔数 / 收入总笔数 | < 5% | > 15% | > 30% |
| 3 | 散进整出比 | (小额多笔收入,大额少笔支出)的天数 / 总交易天数 | < 5% | > 15% | > 30% |
| 4 | 现金交易占比 | 现金交易笔数 / 总交易笔数 | < 20% | > 40% | > 60% |
| 5 | 对手集中度(来源) | TOP3收入金额 / 总收入 | < 30% | > 40% | > 60% |
| 6 | 对手集中度(去向) | TOP3支出金额 / 总支出 | < 30% | > 40% | > 60% |
| 7 | 多对一收入比 | 单日3个以上不同对手转入的天数 / 总交易天数 | < 5% | > 15% | > 30% |
| 8 | 一对多支出比 | 单日向3个以上不同对手转出的天数 / 总交易天数 | < 5% | > 15% | > 30% |
| 9 | 定额交易占比 | 相同金额交易笔数最多的前5个金额合计笔数 / 总笔数 | < 10% | > 25% | > 40% |
| 10 | 快进快出天数占比 | 同日进出均>5万的天数 / 总交易天数 | < 5% | > 10% | > 20% |
| 11 | 资金周转率 | 交易总额 / 平均余额 | < 20 | > 50 | > 100 |
| 12 | 同名账户数 | 对手户名=主体户名的不同账户数 | 0 | >= 2 | >= 5 |
| 13 | 涉众关键词笔数 | 摘要含特定关键词的笔数 | 0 | >= 1 | >= 10 |
| 14 | 地域集中度 | 证件号前6位相同最多的组占总对手比例 | < 10% | > 20% | > 30% |
| 15 | 对手开户银行集中度 | TOP1开户银行对手账户数 / 总对手数 | < 20% | > 30% | > 40% |
| 16 | 提成发放规律性 | 存在固定周期向固定对手发放相近金额的模式 | 无 | 月度 | 周度 |
| 17 | 同IP/MAC账户数 | 出方向共享IP/MAC的账户数 | 1 | >= 3 | >= 5 |

**涉众犯罪特征关键词**（用于指标13的摘要匹配）：
- 传销类：入门费、会员费、加盟费、升级费、培训费、工资、提成、奖金、分红、服务费、管理费、运营费
- 非法集资类：投资款、本金、利息、返利、收益、回报、解债、易物、消费币、积分
- 通用类：会费、份额、股权、期权、理财、托管

补充指标（如数据支持）：
- 自身转账笔数和金额占比
- 30分钟内进出配对数
- 非工作时间（22:00-08:00）交易占比
- **开户时间集中度**：多个涉案账户在短时间内集中开户
- **公共卡识别置信度**：同一账户收到特征金额转入的不同对手数量

## 犯罪模式识别规则

根据可疑指标的组合，匹配以下犯罪模式。可能同时符合多种模式，逐一判断。

**聚集型传销（入门费型）**：
- 存在明显的入门费特征值（如2900/5800/69800等固定金额高频出现）
- 多对一收入+一对多支出模式显著
- 现金交易占比高（下级取现→上级存现进行物理隔离）
- 存在定期发放提成的规律
- 地域集中度高（老乡传销）
- 同IP/MAC共享账户多（经理室统一操作）

**网络传销（平台型）**：
- 资金通过第三方支付平台（支付宝/财付通）大量流转
- 存在对公账户参与（平台运营公司账户）
- 快进快出特征明显
- 摘要含"会员""充值""提现"等关键词
- IP/MAC地域分散但部分集中（技术/财务团队）
- 资金最终流向少数几个实控人账户

**非法吸收公众存款**：
- 大量来源分散的小额资金汇入（不特定公众投资）
- 存在定期返利模式（如按月返还利息）
- 资金部分用于还本付息形成资金回流
- 涉案公司账户与个人账户间大量资金往来
- 可能存在真实经营活动（但不足以覆盖返利承诺）

**集资诈骗**：
- 类似非法吸收公众存款的资金归集特征
- 但资金大量流向实控人个人消费、购房、购车、购汇
- 几乎无真实投资项目或经营活动
- 返利资金主要来自新投资人（庞氏骗局特征）
- 资金沉淀比例高（实控人大量截留）

**涉诈投资平台**：
- 资金通过对公账户大量归集
- 存在多家关联公司间的资金流转（股权关联）
- 快进快出显著，资金呈现"快速过境"特征
- 部分资金流向第三方支付平台（支付宝对公账户）
- IP/MAC分析可定位作案窝点

**虚拟币传销/跑分**：
- 资金流向第三方支付平台后消失（转为虚拟币）
- 交易摘要含"交易所""购币""承兑""USDT"等关键词
- 单笔金额较大，过账频率高
- 银行卡层级相对较少，资金快速流转

匹配到模式后，在报告中按"资金层级模型"描述：

**传销类四层模型**：
1. **入门费归集层**：底层成员缴纳入门费→公共卡归集→上级账户
2. **提成分配层**：按层级发放不同档次的提成/工资
3. **资金沉淀层**：扣除各级提成后的净利润沉淀在吸金账户
4. **变现层**：实控人通过消费、购房、购车等方式变现

**非法集资类四层模型**：
1. **集资层**：投资人通过银行转账/现金/第三方支付投入资金
2. **归集层**：资金通过门店财务→区域财务→总部财务逐级归集
3. **返利层**：按承诺比例向投资人返还本息（主要来自新投资人资金）
4. **挥霍/沉淀层**：实控人挪用资金用于个人消费、购置资产或转移

## 离线分析环境限制

本分析在**无法联网的离线环境**下进行，以下外部信息无法获取，需在报告中明确说明并提出补充建议：

1. **股权穿透信息不可用**：无法查询涉案公司的股权架构、关联企业、实际控制人等工商信息（如天眼查、企查查等平台数据）。报告中如需判断公司间关联关系，只能基于交易数据中的资金往来推断，并注明"因无法进行股权穿透查询，公司关联关系为基于资金流向的推断，建议后续补充工商信息核实"。

2. **互联网舆情不可用**：无法搜索涉案公司/平台的网络舆情、投诉信息、媒体报道等。报告中不应引用任何网络搜索结果。如需判断涉案平台的公众影响，建议在"下一步工作建议"中提出"建议补充互联网舆情检索，核查涉案平台在社交媒体、投诉平台（如黑猫投诉、聚投诉）上的相关信息"。

3. **行政处罚/司法记录不可用**：无法查询涉案人员/公司的行政处罚记录、失信被执行人信息、历史涉诉案件等。

4. **银行黑名单/风控信息不可用**：无法查询涉案账户是否已被其他机构标记为可疑账户。

**报告写作要求**：
- 在"九、犯罪模式与资金穿透研判"章节中，判断是否存在非吸事实时，**仅基于交易数据分析结论**，不得引用无法验证的外部信息
- 在"十、下一步工作建议"章节中，**必须专门列出"补充信息获取建议"**，包括建议补充股权穿透查询、互联网舆情检索、行政处罚记录核查等
- 对于仅凭交易数据无法确认的结论（如公司是否有真实经营、产品是否有真实价值等），应注明"受限于离线分析环境，该结论需进一步核实"

### 数据列名不匹配

常见列名对照：

| 标准字段 | 可能的其他列名 |
| --- | --- |

| 交易证件号 | 证件号码、身份证号、证件号 |
| 交易时间 | 交易日期、记账时间、发生日期 |
| 交易金额 | 金额、发生额、交易发生金额 |
| 收付标志 | 借贷标志、交易方向、借贷方向 |
| 交易余额 | 余额、账户余额、当前余额 |
| 交易对手账卡号 | 对手账号、对方账户、对手卡号 |
| 对手户名 | 对方户名、对方姓名、对手名称 |
| 对手证件号 | 对手身份证号、对方证件号码 |
| 对手开户银行 | 对手银行、对方开户行、对手开户网点 |
| 交易发生地 | 交易地点、发生地、地区 |
| 现金标志 | 交易渠道、转账方式 |
| 摘要说明 | 摘要、交易摘要、备注、用途 |
| IP地址 | IP、登录IP、操作IP |
| MAC地址 | MAC、设备MAC、物理地址 |

### Excel文件过大或读取失败

优先使用 `excelcli import` 直接导入目录或单个文件；如导入失败，查看错误信息、编码、表头识别和 `import_issues`，不要改用自行读取脚本。

### 多账户数据的处理

涉众案件通常涉及多个账户，处理策略：
1. 先对每个账户独立进行阶段A分析，判断其角色
2. 再将所有账户的交易明细合并，进行跨账户的资金流向分析
3. 在层级推断时，以"交易卡号"区分不同账户，以"对手账卡号"追踪资金去向
4. 注意主体账户之间的互转（内部转账）要单独标注

### 入门费特征值的自动识别

使用 `excelcli query` 对 `bank_transactions` 的收入端按金额分组计数，重点关注出现次数高、整百整千、与会员费或投资档位相符的金额。

### 分析结果异常

排查步骤：先用 `excelcli inspect` 核对列名和样例，再查看 `import_issues` 与映射文件；必要时调整映射后重新标准化。
