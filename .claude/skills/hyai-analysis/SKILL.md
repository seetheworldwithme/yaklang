# 经侦分析技能 (JingZhen Analysis Skill)
## 数据处理要求（强制）

执行本技能前，先使用 `excelcli-analysis` 完成文件导入、字段识别、标准化、筛选和基础统计。银行流水统一分析 `bank_transactions`；涉税数据统一分析 `tax_invoices`、`seller_invoice`、`buyer_invoice`、`tax_registrations` 等标准表。

本技能只规定查案思路、指标体系、模式识别、报告结构和调证建议；不要在技能中提供自定义代码示例，也不要指导智能体自行读取 Excel/CSV 或自建入库流程。


> 本技能用于分析火眼金睛经侦分析软件的业务逻辑，具备经侦资金分析能力。

## 一、核心分析流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  数据导入   │ → │  格式识别   │ → │  字段映射   │ → │  数据清洗   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                              ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  结果输出   │ ← │  图表展示   │ ← │  战法执行   │ ← │  战法选择   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 分析步骤

1. **数据源识别**：判断数据来源类型（银行流水、支付宝、微信、话单等）
2. **格式匹配**：通过MD5校验和列名匹配识别数据模板
3. **字段标准化**：将原始字段名映射到标准字段体系
4. **数据清洗**：执行清洗规则（时间格式、借贷标志、代码转换）
5. **战法分析**：选择合适的分析战法进行资金追踪
6. **结果输出**：返回分析结果数据集

## 四、借贷标志统一规则

### 标准化映射
```
原始值 → 标准值
─────────────────
收入/贷/进/C/入账 → 进
支出/借/出/D/出账 → 出
```

### 判断逻辑
1. **收款方为主控账户** → 借贷标志 = "进"
2. **付款方为主控账户** → 借贷标志 = "出"
3. 需要交换付款方/收款方信息以统一方向

- 将MCC码转换为商户类型描述

- 将收单机构代码转换为机构名称
- 例如：`001` → `中国银联`

- 将发卡机构代码转换为银行名称
- 例如：`01020000` → `工商银行`

- 将交易代码转换为交易类型
- 例如：`01` → `取款`

### 交易渠道

## 八、经侦分析核心方法论

### 1. 资金流向分析
- **追踪原则**：从资金来源到资金去向的全链路追踪
- **分析方法**：按时间顺序、金额关联、账户关联
- **关注重点**：大额交易、频繁交易、异常时间交易

### 2. 异常交易识别
- **快进快出**：短时间内资金进出频繁
- **特殊金额**：整数金额、重复金额、特定规律金额
- **异常时间**：深夜交易、节假日交易
- **异常地点**：跨地区交易、异常交易地点

### 3. 关联账户分析
- **共同联系人**：多个账户的共同交易对象
- **共同IP/MAC**：相同设备登录的账户
- **资金回流**：资金循环流动模式
- **分层次追踪**：一级、二级、多级账户关联

### 4. 反洗钱分析
- **数据分块**：按主控人拆分交易数据
- **方向统一**：统一付款方/收款方格式
- **主控账户识别**：识别实际控制账户

## 九、使用指南

### 分析任务启动
当用户需要进行经侦分析时，按以下流程执行：

1. **确认数据类型**：询问用户要分析的数据来源类型
2. **选择分析维度**：单卡/多卡/微信/支付宝
3. **确定分析目标**：资金追踪/异常识别/关联分析
4. **推荐战法**：根据目标推荐合适的分析战法
5. **执行分析**：按照战法逻辑进行分析
6. **输出结果**：以表格形式展示分析结果

### 常见分析场景
| 场景 | 推荐战法 |
|------|---------|
| 追踪一笔资金去向 | FundTrace_Method, FundAccurateTrace_Method |
| 分析账户交易规律 | TransactionFrequencies_Method, TimeRule_Method |
| 识别洗钱账户 | FastEnterAndOut_Method, AbnormalAccount_Method |
| 分析多账户关系 | JointAccountAnalyze_Method, TransactionPath_Method |
| 分析微信交易 | ZqyWeChat* 系列战法 |
| 分析支付宝交易 | ZqyAlipay* 系列战法 |
