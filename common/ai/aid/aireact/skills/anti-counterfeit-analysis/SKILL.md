# 假币犯罪分析

假币犯罪数据分析的完整方法论。本技能提供分析框架、领域知识、判断规则和参考代码，帮助你完成从线索发现到团伙研判的全流程。

## 适用场景

当用户提供以下类型数据并要求分析假币犯罪时使用：
- 前科人员信息（手机号、邮箱、证件号等）
- 网盘数据（文件列表、操作记录、IP地址）
- 银行/支付交易数据
- 物流购买记录
- 通讯数据（通话记录、微信、QQ等）
- 轨迹数据（车辆、人员活动）

## 分析框架

分析分为五个阶段，按顺序执行。每个阶段完成后检查产出是否齐全再进入下一阶段。

### 阶段A：前科人员信息收集与画像

**目标**：建立假币犯罪重点人员库，全面刻画人员背景和关联网络。

**必须产出的指标**：
- 涉假币前科人员数量
- 人员基本信息（姓名、证件号、手机号、电子邮箱）
- 家庭成员、亲戚关系（兄弟姐妹、堂亲、表亲等）
- 通讯录频繁联系人（前20位）
- 历史涉案情况（案件类型、时间、处理结果）

**关联分析要点**：
- 同户人员关联
- 同行人员关联
- 同住人员关联
- 车辆共同使用关联

### 阶段B：网盘模板穿透分析

**目标**：通过网盘工具获取假币电子模板信息，挖掘制售假币线索。

**操作要领**：

1. **网盘注册信息比对**
   - 前科人员手机号与网盘注册信息碰撞
   - 前科人员电子邮箱与网盘注册信息碰撞
   - 获取匹配的网盘UID及文件列表

2. **假币电子模板识别**

   | 面额 | 常见暗语命名 |
   | --- | --- |
   | 10元 | 蓝、蓝天、一帆风顺 |
   | 20元 | 黄、黄鱼、Y、一帆风顺 |
   | 50元 | 青、青蛙、绿 |
   | 100元 | 红、红牛、风生水起、九五至尊、百元模板 |

   **关键特征**：
   - 文件后缀：.psd（Photoshop格式）
   - 文件大小：通常数MB至数十MB
   - 命名规则：暗语或直接标注面额

3. **网盘操作记录分析**

   **必须分析的操作类型**：
   - 登录记录（时间、IP地址、端口）
   - 上传记录（文件名、时间、IP）
   - 下载记录（时间、IP）
   - 分享记录（分享对象、时间）
   - 被下载记录（下载者UID、时间、IP）
   - 删除记录

4. **身份落地**
   - 通过下载者UID反查实名手机、邮箱
   - 通过IP地址定位活动范围
   - 交叉碰撞确认真实身份

### 阶段C：制假材料物流特征分析

**目标**：通过物流购买记录识别制假窝点和规模。

**可疑材料清单**：

| 序号 | 材料名称 | 可疑特征 |
| --- | --- | --- |
| 1 | 证券纸 | 购买80g或90g（接近人民币85g），正常A4纸为70g |
| 2 | 6色打印机 | 一次性购买2台以上（如爱普森R330） |
| 3 | 水性油墨 | 配合打印机购买 |
| 4 | 扫描仪 | 与其他材料组合购买 |
| 5 | 烫金机 | 专用于假币加工 |
| 6 | 烫金线 | 配合烫金机使用 |
| 7 | 金粉 | 用于假币表面处理 |
| 8 | 丝网 | 印刷耗材 |
| 9 | 切纸机 | 裁切成品 |
| 10 | 清零软件 | 打印机/扫描仪计数清零 |
| 11 | 图像处理软件 | Photoshop等 |

**预警规则**：
- 同一人购买**2种以上**上述材料即视为可疑线索
- 爱普森R330打印机打印效率：平均2分钟/张

**物流分析要点**：
- 收货地址分析（是否偏僻村庄、出租屋）
- 收货人与购买人关系
- 购买时间序列（初期少量测试→后期批量采购）
- 购买数量与窝点规模关联

### 阶段D：四流研判分析

**目标**：综合分析人员流、信息流、资金流、物流，全面刻画犯罪网络。

#### D1 人员流分析

**分析方法**：
- 同户、同行、同住、车辆轨迹关联
- 反侦查较强嫌疑人可采取外线侦查
- 分析"物理隔断"的团伙成员

**关键指标**：
- 团伙成员数量
- 成员间关系（亲属、同乡、朋友）
- 成员活动轨迹重合度
- 偏僻地区活动记录

#### D2 信息流分析

**分析内容**：
- 通话记录（频率、时段、时长）
- 微信/QQ等即时通讯
- 异常通话模式识别

**可疑模式**：
| 模式 | 特征 | 可疑阈值 |
| --- | --- | --- |
| 异常开关机 | 离开居住地后关机，回到居住地后开机 | 频繁出现 |
| 深夜通话 | 凌晨1时至5时通话 | 多次出现 |
| 多机多号 | 1人持有多部手机、多个电话号码 | >=2部手机 |
| 虚拟号码 | 使用虚拟手机号码 | 存在即可疑 |

**虚拟号码拓线方法**：
1. 查询虚拟运营商归属（银盛通信、长城移动、迪信通等）
2. 调取开户信息、话单、话费充值记录
3. 分析通话对端信息
4. 查询话费充值的银行/支付宝账号
5. 查询登录设备IMEI信息，反查插换卡记录
6. 查询连接的WiFi及相关设备
7. 查询绑定的微信、支付宝、QQ账号
8. 查询外卖、网购、打车等消费记录

#### D3 资金流分析

**分析内容**：
- 银行卡大额现金存入（一次性5万以上或月存10万以上）
- 支付交易信息（银行卡、支付宝、微信、POS机）
- 资金往来模式

**假币交易特征**：
| 特征 | 说明 |
| --- | --- |
| 一级分销价 | 7-9元/张（100元面额假币） |
| 交易方式 | 多使用现金，银行流水难以追踪 |
| 大额存入 | 销售后现金存入银行 |
| 快进快出 | 资金快速流转 |

**可疑指标**：
- 收支高度平衡（平衡度 < 5%）
- 现金交易占比高（> 50%）
- 大额现金存入频次
- 资金周转率极高（> 50）

#### D4 物流分析

**分析要点**：
- 购买制假工具和原材料记录
- 购买序列分析（测试期→批量期）
- 车辆异常活动（凌晨1-5时省际交界处活动）

**收网时机研判**：
| 信号 | 说明 |
| --- | --- |
| 进货量增加 | 样品制作达标后批量购买证券纸、油墨 |
| 出货量增加 | 出货频率高，银行卡大额存入增多 |
| 窝点转移 | 半成品从生产窝点→二次加工窝点→存储窝点 |
| 人员频繁进出 | 主要犯罪嫌疑人进入窝点频率增加 |

### 阶段E：窝点定位与团伙识别

**目标**：锁定制假窝点位置，识别团伙组织架构。

#### E1 窝点类型

| 窝点类型 | 功能 | 识别特征 |
| --- | --- | --- |
| 生产窝点 | 假币印制 | 有打印设备、证券纸、油墨等 |
| 二次加工窝点 | 烫金、裁切等后处理 | 有烫金机、切纸机等 |
| 成品储藏窝点 | 假币存储 | 物流进出频繁，人员活动少 |

#### E2 窝点定位方法

1. **电子侦控**
   - 通过生活号码关联作案专用号码
   - 发现长期在窝点活动的人员手机号
   - 技术侦察定位窝点位置

2. **动态跟踪**
   - 蹲点守候异常开关机地点
   - 物流跟踪（快递取件点反查）
   - 视频追踪（路段监控分析）

3. **地址分析**
   - 偏僻村庄或区域
   - 出租房屋
   - 物流收货地址附近

#### E3 团伙组织架构

**典型层级结构**：
```
┌─────────────────┐
│   核心控制人     │ ← 组织策划、技术掌握
└────────┬────────┘
         │
┌────────▼────────┐
│   生产操作人     │ ← 负责印制、加工
└────────┬────────┘
         │
┌────────▼────────┐
│   销售分销人     │ ← 负责销售、运输
└────────┬────────┘
         │
┌────────▼────────┐
│   外围协助人     │ ← 提供场地、物流等
└─────────────────┘
```

## 可疑指标与阈值

以下是核心可疑指标的计算方法和判定阈值。

| 序号 | 指标名称 | 计算方法 | 正常范围 | 异常阈值 | 高度异常 |
| --- | --- | --- | --- | --- | --- |
| 1 | 制假材料购买种类数 | 购买可疑材料种类数 | 0-1种 | 2-3种 | >=4种 |
| 2 | 深夜通话占比 | 1-5时通话数/总通话数 | < 5% | > 10% | > 20% |
| 3 | 异常开关机次数 | 离开居住地关机次数 | 0 | >= 3次/月 | >= 10次/月 |
| 4 | 网盘模板文件数 | 假币相关psd文件数 | 0 | >= 1 | >= 5 |
| 5 | 大额现金存入占比 | 5万以上现金存入笔数/总存入笔数 | < 10% | > 30% | > 50% |
| 6 | 设备共享人数 | 同一设备关联的人数 | 1人 | >= 2人 | >= 5人 |
| 7 | 地域集中度 | 同乡人员占比 | < 20% | > 40% | > 60% |
| 8 | 亲属关联度 | 团伙中亲属关系占比 | < 20% | > 40% | > 60% |

## 犯罪模式识别规则

根据可疑指标的组合，匹配以下犯罪模式。

**家族式制售假币**：
- 团伙成员多为亲属关系
- 地域高度集中（同乡）
- 有明确的家族核心控制人
- 生产窝点隐蔽（自家房屋或偏僻地区）

**专业团伙制售假币**：
- 成员有涉假币前科
- 分工明确（生产、加工、销售、存储）
- 反侦查意识强（虚拟号码、异常开关机）
- 多窝点协作（生产窝点→加工窝点→存储窝点）

**网络分销型假币犯罪**：
- 网盘模板广泛传播
- 多层分销网络
- 线上联络、线下交易
- 使用暗语沟通

## 数据文件说明

典型的假币犯罪分析数据包含以下类型文件：

### 1. 前科人员信息表

**标准字段**：姓名、证件号码、手机号码、电子邮箱、涉案类型、案发时间、处理结果、家庭住址

### 2. 网盘数据表

**标准字段**：网盘UID、绑定手机、绑定邮箱、文件名、文件类型、文件大小、上传时间、上传IP、下载时间、下载IP、分享对象、操作类型

### 3. 物流购买记录表

**标准字段**：购买人姓名、购买人手机、购买时间、商品名称、商品数量、收货地址、收货人、快递单号

### 4. 通讯记录表

**标准字段**：主叫号码、被叫号码、通话时间、通话时长、通话地点、IMEI、基站信息

### 5. 交易明细表

**标准字段**：交易卡号、交易户名、交易时间、交易金额、收付标志、对手账户、对手户名、摘要说明、交易发生地、现金标志

## 常见问题处理

### 数据列名不匹配

不同系统导出的数据列名差异很大。先打印列名再适配：

```python
print(df.columns.tolist())
```

### 网盘数据不完整

- 如只有部分网盘数据：重点分析已有数据，在报告中注明数据范围
- 如缺少IP地址：仅做文件内容分析，无法进行地理定位
- 如缺少操作记录：仅做静态文件分析

### 物流数据缺失

- 如只有购买记录无收货地址：跳过窝点定位分析
- 如收货地址为超市/门店：需进一步追踪实际取货人

### 通讯数据受限

- 如无法获取技侦数据：重点分析已有公开信息
- 如只有话单无内容：通过通话频率、时段进行模式分析
