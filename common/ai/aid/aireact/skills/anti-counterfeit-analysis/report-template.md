# 假币犯罪分析报告模板

以下为八章结构的报告模板。每章包含**必须覆盖的内容项**和**写作风格指引**。根据实际数据填入分析结果，措辞和详略可自由调整。

---

## 一、案件概述

### （一）案件背景

简述案件来源、背景情况、分析任务的起因。

**必须包含**：
- 案件来源（群众举报、银行收缴、平台预警、案件关联等）
- 涉及的主要问题（伪造货币、出售假币、购买假币、运输假币等）
- 初步掌握的线索情况

**写作指引**：简洁明了，1-2段文字说明背景。

### （二）分析目标

明确本次分析的目标和预期产出。

**示例**：
- 识别假币制售团伙成员
- 锁定制假窝点位置
- 刻画犯罪网络架构
- 估算涉案规模

### （三）数据来源

列出本次分析使用的数据类型和范围。

**建议格式**：

| 数据类型 | 数据来源 | 时间范围 | 记录数 |
| --- | --- | --- | --- |
| 前科人员信息 | 公安数据库 | - | {数量}人 |
| 网盘数据 | 百度网盘调证 | {起始日期}-{结束日期} | {数量}条 |
| 物流记录 | 淘宝/京东购买记录 | {起始日期}-{结束日期} | {数量}条 |
| 交易流水 | 银行调证 | {起始日期}-{结束日期} | {数量}笔 |

### （二）可疑度评估

根据购买材料种类评估可疑程度。

**预警规则**：同一人购买2种以上可疑材料视为可疑线索。

**建议格式**：

**XXX的可疑材料购买统计**：

### （三）购买序列分析

分析材料购买的时间序列，研判窝点阶段。

**必须包含**：
- 初期（测试阶段）：少量购买纸张、油墨
- 中期（调试阶段）：购买设备，测试制假"质量"
- 后期（批量阶段）：大批量购买原材料

**建议格式**：

| 阶段 | 时间范围 | 购买材料 | 研判结论 |

| 批量期 | {时间} | 大量证券纸、多台打印机 | 批量生产阶段 |

### （四）规模研判

根据材料购买量估算窝点生产规模。

**参考指标**：
- 爱普森R330打印机效率：约2分钟/张
- 1台打印机日产量：约30张（按10小时计）
- 证券纸消耗：1张纸印1张假币

**规模估算示例**：
> 购买证券纸{数量}包（每包{张数}张），按1台打印机日产量{数量}张计算，预计生产周期约{天数}天，总产量约{数量}张假币。

## 格式规范

1. **报告标题**：`{案件名称/线索编号}假币犯罪分析报告`
2. **数值格式**：金额保留2位小数并加千分位（如 1,234,567.89 元）
3. **表格**：重要数据必须以表格展示，不要纯文字堆砌
4. **章节编号**：使用"一、二、三……"作为一级标题，"（一）（二）（三）……"作为二级标题
5. **段落结构**：分析类段落采用"一是……二是……三是……"的递进结构
6. **语言风格**：正式、客观、专业。使用"该人员""涉案账户"而非"这个人"
7. **数据缺失说明**：如因数据字段缺失而跳过某项分析，必须在对应位置注明原因
