# 资金穿透分析

资金穿透分析的完整方法论。本技能提供分析框架、领域知识、判断规则，帮助你完成从数据探查到多层穿透的全流程分析。

---

## 一、数据输入规范

### 1.1 核心数据格式

用户提供的交易数据应包含以下字段（CSV、Excel或JSON格式）：

```
必要字段：
- 交易方账号/卡号：发起交易的账户
- 交易户名：账户持有人姓名
- 对手方账号/卡号：交易对手的账户
- 对手户名：交易对手姓名
- 交易金额：单笔交易金额（数值型）
- 交易时间：交易发生时间
- 收付标志：进/出/收/付/存/取 等标识

可选字段：
- 证件号码
- 摘要/备注
- IP地址
- MAC地址
- 交易渠道（网银/ATM/柜台等）
```

### 1.2 收付标志映射

```
进账标识：进、收、入、贷、转入、收款
出账标识：出、付、取、借、转出、付款
```

## 三、核心分析逻辑

### 3.1 资金来源分析

**目的**：识别被调查账户的主要资金来源

**分析逻辑**：
```
1. 筛选条件：收付标志 IN (进账标识列表)
2. 分组维度：对手户名 + 对手账号
3. 聚合指标：
   - 转入总金额 = SUM(交易金额)
   - 转入笔数 = COUNT(*)
   - 首次交易时间 = MIN(交易时间)
   - 最后交易时间 = MAX(交易时间)
4. 过滤阈值：转入总金额 >= 10,000元
5. 排序：按转入总金额降序
```

**输出格式**：
| 排名 | 对手户名 | 对手账号 | 转入金额 | 转入笔数 | 首次交易 | 最后交易 |
|------|----------|----------|----------|----------|----------|----------|

### 3.2 资金去向分析

**目的**：识别被调查账户的主要资金去向

**分析逻辑**：
```
1. 筛选条件：收付标志 IN (出账标识列表)
2. 分组维度：对手户名 + 对手账号
3. 聚合指标：
   - 转出总金额 = SUM(交易金额)
   - 转出笔数 = COUNT(*)
   - 首次交易时间 = MIN(交易时间)
   - 最后交易时间 = MAX(交易时间)
4. 过滤阈值：转出总金额 >= 10,000元
5. 排序：按转出总金额降序
```

### 3.3 即进即出分析（洗钱中转账户）

**目的**：识别资金快速进出的可疑账户

**识别逻辑**：
```
Step 1: 按账户分别统计进账和出账
  - 进账总额 = SUM(进账交易金额)
  - 出账总额 = SUM(出账交易金额)
  - 进账笔数 = COUNT(进账记录)
  - 出账笔数 = COUNT(出账记录)

Step 2: 计算关键指标
  - 进出差值 = |进账总额 - 出账总额|
  - 进出差率 = 进出差值 / MAX(进账总额, 出账总额)
  - 净额 = 进账总额 - 出账总额

Step 3: 判断即进即出特征（需同时满足）
  ✓ 交易总额 >= 50,000元
  ✓ 进出差值 <= 1,000元 或 进出差率 <= 10%
  ✓ 进账笔数 >= 3 且 出账笔数 >= 3
```

**可疑等级判定**：
| 等级 | 条件 | 说明 |
|------|------|------|
| 高风险 | 进出差率 < 5% 且 交易总额 > 100,000 | 高度疑似洗钱中转 |
| 中风险 | 进出差率 < 10% 且 交易总额 > 50,000 | 需重点关注 |
| 低风险 | 进出差率 < 20% 且 交易总额 > 10,000 | 建议进一步核查 |

### 3.4 过渡账户分析

**目的**：识别作为资金中转站的账户

**识别逻辑**：
```
判断条件（需同时满足）：
  ✓ 交易总金额 >= 10,000元
  ✓ 进账总额 - 出账总额（净额）的绝对值 <= 10,000元
  ✓ 交易笔数 >= 10

可选增强条件：
  ✓ 平均资金停留时间 < 24小时
  ✓ 对手方数量 >= 5（多对多交易）
```

### 3.5 吸金账户分析

**目的**：识别集资/诈骗收款账户

**识别逻辑**：
```
判断条件（需同时满足）：
  ✓ 转入总金额 / 转出总金额 >= 5（钱只进不出）
  ✓ 转入总金额 >= 10,000元
  ✓ 转入笔数 >= 10

增强判定：
  ✓ 转入笔数 / 转出笔数 >= 5
  ✓ 转入对手方数量 >= 10（多人转入）
  ✓ 转出对手方数量 <= 3（少数人转出）
```

### 3.6 集中分散模式分析

#### 模式A：集中转入分散转出（洗钱中转）

```
特征识别：
  ✓ 转入笔数 >= 5 且 转出笔数 >= 5
  ✓ 转入对手方数 / 转出对手方数 >= 3（多人转入，少数人转出）
  ✓ 转入金额 / 转出金额 在 0.8~1.2 之间（金额基本平衡）
  ✓ 单笔转入金额较小，单笔转出金额较大
```

#### 模式B：分散转入集中转出（集资/诈骗）

```
特征识别：
  ✓ 转入笔数 >= 10
  ✓ 转出笔数 <= 5
  ✓ 转入对手方数 >= 10（多人转入）
  ✓ 转出对手方数 <= 3（集中转出给少数人）
  ✓ 转入总金额远大于转出总金额
```

### 3.7 大额交易分析

**目的**：识别异常大额交易

**分析逻辑**：
```
单笔大额：单笔交易金额 >= 设定阈值（如50,000元）
累计大额：与某对手方累计交易金额 >= 设定阈值（如100,000元）

输出指标：
  - 大额交易笔数
  - 大额交易总金额
  - 最大单笔金额
  - 大额交易对手方列表
```

## 四、多层穿透分析

### 4.1 穿透逻辑

```
第一层穿透：
  输入：调查账户A
  输出：A的所有直接交易对手（B1, B2, B3...）
        + 各对手方的交易金额、笔数、时间

第二层穿透：
  输入：第一层的重点对手方（如B1）
  输出：B1的所有交易对手（C1, C2, C3...）
        + 分析B1的资金来源和去向

第三层穿透（如需要）：
  输入：第二层的重点对手方（如C1）
  输出：C1的所有交易对手...

穿透终止条件：
  - 达到设定层数（如3层）
  - 找到资金的最终来源/去向
  - 出现循环（账户已分析过）
```

### 4.2 资金链路追踪

```
正向追踪（追踪去向）：
  A → B1 → C1 → D1 → ... → 最终去向

反向追踪（追踪来源）：
  A ← B1 ← C1 ← D1 ← ... ← 最初来源
```

## 五、关联分析

### 5.1 共同对手分析

**目的**：证明多个调查对象存在关联

**分析逻辑**：
```
输入：调查对象列表 [A, B, C, ...]

Step 1: 获取各调查对象的交易对手集合
  Set_A = {A的所有对手方}
  Set_B = {B的所有对手方}
  Set_C = {C的所有对手方}

Step 2: 计算交集
  共同对手 = Set_A ∩ Set_B ∩ Set_C

Step 3: 排除正常机构
  排除关键词：银行、支付宝、财付通、微信、证券、保险、
            基金、电信、移动、联通、电力、水务、燃气、
            医院、学校、政府、平台、电商等

Step 4: 输出结果
  - 共同对手列表
  - 各调查对象与共同对手的交易明细
  - 关联强度评估
```

### 5.2 群组分析

**目的**：识别有组织的账户群组

**分析逻辑**：
```
识别标准：
  1. 多个账户有共同的资金往来
  2. 账户之间存在相互转账
  3. 与同一批对手方交易
  4. 交易时间、金额存在相似性

群组识别方法：
  - 基于共同对手的聚类
  - 基于交易频率的关联
  - 基于金额模式的相似性
```

## 九、注意事项

### 9.1 数据处理注意事项

1. **数据清洗**：处理前需去除重复记录、补全缺失字段
2. **格式统一**：统一金额格式、时间格式、账户格式
3. **收付标志**：需正确识别各种收付标志表述
4. **金额符号**：注意金额可能为负数表示出账

### 9.2 分析注意事项

1. **阈值调整**：默认阈值仅供参考，需根据案件具体情况调整
2. **排除正常交易**：银行转账、工资发放等正常交易需排除
3. **时间因素**：关注异常时间段（深夜、节假日）的交易
4. **小额高频**：拆分交易也是常见洗钱手法
5. **交叉验证**：多种分析方法结果应相互验证

### 9.3 结果解读注意事项

1. **可疑≠犯罪**：分析结果仅供参考，需进一步调查核实
2. **证据链**：单一分析结果不足以作为证据
3. **隐私保护**：注意保护无关人员的隐私信息
4. **报告规范**：分析报告应符合法律文书规范
