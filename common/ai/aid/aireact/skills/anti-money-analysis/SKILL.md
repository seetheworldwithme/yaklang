# 资金交易分析

可疑交易资金分析的完整方法论。本技能提供分析框架、领域知识、判断规则和参考代码，帮助你完成从数据探查到报告撰写的全流程。

## 数据文件说明

典型的资金分析数据包含以下四类文件（文件名可能不同，以实际列名为准）：

### 1. 交易明细（主表）

核心数据文件，每条记录为一笔交易，包含收付双方完整信息。所有分析的主要数据来源。

**标准字段**：交易卡号、交易账号、交易户名、交易证件号、交易时间、交易金额、交易余额、收付标志（进/出）、交易对手账卡号、对手户名、对手证件号、对手开户银行、摘要说明、交易币种、交易网点名称、交易发生地、交易是否成功、传票号、IP地址、MAC地址、对手交易余额、交易流水号、凭证号、交易柜员号、现金标志、备注

### 2. 人员信息（辅助表）

涉案客户的身份和背景信息，用于补充对手身份背景、工作单位等。

**标准字段**：客户名称、证照类型、证照号码、单位地址、单位电话、工作单位、邮箱地址、代办人姓名、代办人证件类型、代办人证件号码、国税纳税号、地税纳税号、法人代表、客户工商执照号码

### 3. 账户信息（辅助表）

涉案账户的开户属性和状态信息，用于报告"账户基本信息"章节。

**标准字段**：账户开户名称、开户人证件号码、交易卡号、交易账号、账号开户时间、账户余额、币种、开户网点代码、开户网点、账户状态、账户类型、账号开户银行

### 4. 子账户信息（辅助表）

涉案账户的子产品/子类别信息（如定期、理财、贷款等），用于展示账户的完整资金结构。

**标准字段**：银行名称、开户账号、子账户账号、余额、可用余额、子账户类别、币种、钞汇标识、账户状态

> **文件匹配原则**：用户提供的文件可能名称不同，但通过列名可以识别文件类型。优先匹配交易明细，再通过"交易卡号/交易户名/证照号码"等关键字段关联辅助表。

## 分析框架

分析分为四个阶段，按顺序执行。每个阶段完成后检查产出是否齐全再进入下一阶段。

### 阶段A：数据探查与交易画像

**目标**：了解账户全貌，建立基础数据认知，并对账户进行初步分类。

**操作**：读取数据文件，确认列名和数据格式，然后计算以下指标。

**首先检查账户数量**：读取交易明细后，先统计"交易卡号"列的唯一值数量，确认数据中涉及几个主体账户。如果只有1个账户则为单账户分析；如果有多个账户，需在报告开头列出所有涉案账户，后续分析分别或合并进行（取决于业务需求）。

**数据预处理**：
1. 过滤失败交易：如"交易是否成功"列存在，需先检查该列的实际取值（`df['交易是否成功'].unique()`），不同银行的取值可能为1/"1"/"成功"/True/"Y"/"是"等。**仅过滤明确标识为失败的记录**（如值为0/"0"/"失败"/False/"N"/"否"/"交易失败"），其余记录均应保留。**切勿因为该列的取值格式不标准就删除大部分数据**。如果该列的取值难以判断成功/失败，则不过滤该列，在报告中注明"因交易成功状态列取值格式不明确，未做失败交易过滤"。过滤前后记录数差异应在合理范围内（如差异>50%说明过滤条件有误，需重新检查取值）
2. 交易时间列需转为 datetime：`pd.to_datetime(df['交易时间'])`
3. 收付方向通常在"收付标志"列，值为"进"/"出"，先确认具体取值
4. 用 `df.columns.tolist()` 和 `df.head()` 确认实际列名
5. **不要对"交易卡号"列做格式校验或过滤**（不要要求卡号必须为纯数字、不要要求卡号长度>=16位、不要过滤卡号为空的记录）。实际数据中卡号可能为空（仅有账号）、可能包含非数字字符、长度可能不固定。"交易卡号"和"交易账号"是两个不同字段，有账号无卡号是正常情况。主体账户识别优先使用"交易户名"或"交易账号"，"交易卡号"为空不应导致记录被丢弃
6. 关联辅助表：通过"交易卡号"或"交易户名"关联账户信息和人员信息，补充账户属性和人员背景

**必须产出的指标**：
- 涉及主体账户数量（单账户/多账户）
- 交易笔数、交易总额、时间跨度（首尾日期和天数）
- 收入/支出分别的笔数和金额
- 收入/支出分别的平均单笔金额
- 收入/支出分别涉及的对手户名去重个数（按"对手户名"字段去重统计，反映实际交易涉及的自然人/法人数量，与按对手账卡号统计的对手账户数不同）
- 收支平衡度（差额/总额）
- 年度交易趋势（按年分组的进出笔数、金额、以及每年进出分别涉及多少个对手主体）
- 金额分布（按 0-1千/1千-5千/5千-1万/1万-5万/5万-10万/10万-50万/50万以上 共7个区间，分别统计进出笔数）
- 现金交易笔数、金额、占比（如数据中有"现金标志"列）
- 余额特征：最高/最低/平均/最终余额（如数据中有"交易余额"列）
- 日均交易笔数
- **交易地理分布**：按"交易发生地"统计交易笔数和金额，识别主要交易地区（如数据中有该字段）
- **对手开户银行分布**：按"对手开户银行"统计对手账户数，识别资金主要流向的银行机构（如数据中有该字段）
- **账户开户信息**：从账户信息表汇总所有涉案账户的开户时间、开户网点、账户类型、账户状态等（如提供了账户信息文件）。**注意**：涉案账户信息表中的"当前余额"字段不从账户信息表取值，而是从交易明细中筛选该卡号的所有交易记录，按交易时间排序后取最后一笔的"交易余额"字段值，以确保余额反映最新交易后的真实状态
- **子账户结构**：从子账户信息表展示涉案账户的子产品分布和资金分布（如提供了子账户信息文件）

**账户分类（交易比值法）** `[来源：技战法3"三取四辨"]`：

对每个主体账户以及所有对手账户，计算**交易比值** = 收入 / (收入 + 支出)，按以下区间分类：

| 比值区间 | 账户类型 | 说明 |
| --- | --- | --- |
| 0.8 ~ 1.0 | 资金来源账户 | 几乎只有进账，为上游资金提供者 |
| 0.6 ~ 0.8 | 偏来源型账户 | 以进账为主，可能为团伙财务账户 `[来源：技战法3"三取四辨"]` |
| 0.4 ~ 0.6 | 过渡/中转账户 | 进出相当，资金快进快出 |
| 0.2 ~ 0.4 | 偏去向型账户 | 以出账为主 |
| 0.0 ~ 0.2 | 资金去向账户 | 几乎只有出账，为下游资金接收者 |

**特殊比值标记** `[来源：技战法3"三取四辨"]`：
- 比值 = 1.0 → 虚开通道账户（仅有进账无出账）
- 比值 = 0.0 → 钱庄指定账户（仅有出账无进账）
- 比值 ≥ 0.99 → 高度可疑的单向流入账户

**财务账户识别** `[来源：技战法3"三取四辨"]`：比值绝对值介于 0.6~0.9，且账户余额超过10万元的次数 ≥ 3次的交易对手，标注为疑似团伙财务账户。

**汇率匹配检测（"智汇"模型）** `[来源：技战法9"智汇猎手"]`：

对交易明细中金额个位非零或含小数部分的交易，按交易当日人民币汇率（美元、欧元、英镑、港币、日元、澳元、台币等常见外币）进行换算，若折算结果趋近整百、整千、整万（偏差≤100），则标注对应币种标签。判定规则：
- 同一账户被打上同一币种标签的交易条数 > 10、涉及对手 > 5个、涉及不同日期 > 5天 → 高度疑似非法换汇账户
- 标签币种可推断钱庄服务的客户群体（如频繁美元标签 → 服务移民美国客户）

**一次性交易对手占比** `[来源：技战法9"智汇猎手"]`：

统计仅与主体账户交易1-2次的对手数占总对手数的比例。
- 占比 > 70%：高度异常，提示典型钱庄特征（大量一次性客户）
- 占比 > 50%：异常
- 正常商业账户的一次性对手占比通常 < 30%

**账户休眠-激活检测** `[来源：技战法1"四步"、技战法8"比判分锁"]`：

对每个账户计算月度交易频次，识别以下模式：
- **休眠期**：连续30天以上无任何交易
- **激活期**：休眠后突然出现高频交易（日均 ≥ 5笔）
- **静默-爆发比**：激活期日均交易笔数 / 前12个月日均交易笔数 > 10倍，视为异常激活
- 在报告中标注账户的活跃/休眠周期，如"该账户2022年1-6月处于休眠状态，7月突然激活，日均交易达15笔"

**交错活跃-沉睡检测** `[来源：技战法9"智汇猎手"]`：

检测同一主体名下多个账户是否呈现"交错活跃、交错沉睡"的规避监管模式：
1. 对同一主体（证件号相同）名下的多个账户，按月计算各账户的交易活跃度
2. 若A账户活跃期对应B账户沉睡期，且B激活后A随即沉睡 → 交替使用规避监管
3. 阈值：连续活跃月数 ≤ 3个月后切换为另一账户

**非工作时间交易分析** `[来源：技战法9"智汇猎手"]`：

统计夜间交易（22:00-08:00）占比：
- 占比 > 30%：高度异常，提示涉赌（夜间活跃为网络赌博典型特征）或跨时区换汇
- 时间峰值在22时至凌晨7时 → 疑似接收赌博资金
- 进一步分析收入端和支出端的时间分布差异

**字段缺失处理**：如无交易余额字段，跳过余额特征和财务账户识别；如无交易发生地，跳过地理分布。

### 阶段B：资金来源去向分析

**目标**：识别核心交易对手，刻画资金流向模式。

**必须产出的指标**：
- 收入端涉及多少个不同对手账户
- 支出端涉及多少个不同对手账户
- TOP10资金来源表：对手账户、对手户名、对手证件号（用于关联人员信息）、交易笔数、总金额、平均单笔、特征标注
- TOP10资金去向表：同上
- 资金来源集中度：TOP1 / TOP3 / TOP5 占总收入的百分比
- 资金去向集中度：TOP1 / TOP3 / TOP5 占总支出的百分比
- 同名账户识别：对手户名与主体账户户名相同的账户列表及合计金额
- 双向交易对手：既有收入又有支出的对手账户
- 自身转账：对手账户号等于主体账户号的交易统计

**分析要点**：
- 对手信息分布在"交易对手账卡号""对手户名""对手证件号""对手开户银行"等列中
- 可通过"对手证件号"关联人员信息表，获取对手的工作单位、单位地址等背景信息，用于报告中的对手身份描述
- 无对手信息的交易（NaN）单独统计，通常是现金存取
- TOP10表中的"特征"列需人工标注，如"同名账户""高频转入""最大流出""双向交易"等

**对手资金详情分析**：

不仅分析给出用户（涉案主体）的资金详情，还需对重要对手账户进行资金详情分析。具体规则：
1. 对TOP10资金来源和TOP10资金去向中的对手账户，如果该对手在交易明细中也作为"交易卡号"存在（即数据中包含对手自身的交易记录），则对该对手进行与主体账户相同维度的资金详情分析
2. 即使交易明细中不包含对手自身的交易记录（只能看到与主体的交易），也应基于已有数据分析该对手与主体账户的交易模式，包括：
   - 交易时间分布（首次/末次交易时间、活跃时段）
   - 交易金额特征（最大/最小/平均单笔、金额分布）
   - 交易频率特征（日均交易笔数、交易天数集中度）
   - 交易方向分析（是否双向交易、收支比例）
   - 与主体各账户的资金流向明细
3. 对与主体交易金额TOP5的对手，需单独出具"对手资金画像"小节，描述该对手的交易行为特征和疑点

**资金流向结构识别** `[来源：技战法1"四步"、技战法5"一梳二研"]`：

识别以下典型资金流向模式：
- **总进散出**：收入端少量大额、支出端大量小额 → 提示资金分发
- **散进总出**：收入端大量小额、支出端少量大额 → 提示资金归集
- **均衡中转**：收支笔数和金额都较均匀 → 提示过渡账户

判断方法：计算收入端平均单笔金额 / 支出端平均单笔金额，比值 > 3 为"散进总出"，比值 < 0.33 为"总进散出"，其余为"均衡中转"。

**通用摘要识别** `[来源：技战法8"比判分锁"]`：

统计摘要说明字段中使用通用词汇（"货款""往来款""采购款""投资""服务费""汇款""购货"）的交易笔数和金额占比。通用摘要占比 > 60% 视为异常，提示可能使用虚假交易摘要掩饰资金性质。

**字段缺失处理**：如无摘要说明字段，跳过通用摘要分析。

### 阶段C：团伙划分

**目标**：通过设备指纹、地域关联、开户集中度、交易关系和对手重合度识别可能的团伙网络。

**子任务C1 — 基于设备信息的团伙划分**：

IP/MAC地址在交易明细中直接可用，无需单独的对手数据文件：

1. 从交易明细中提取所有支出方向（收付标志="出"）的交易记录
2. 在出账记录中，统计每个IP/MAC地址涉及的"交易卡号"数量（即不同账户出账时使用同一设备）
3. **关键**：只有在出账方向上共享同一IP/MAC的账户才视为设备关联
4. 使用 Union-Find 算法：在出账记录中共享同一IP或MAC的账户归为同一团伙
5. 输出每个团伙的成员、共享IP数、共享MAC数、与主体账户的交易金额

**子任务C2 — 基于对手证件号前6位的地域聚合**：

如交易明细中有"对手证件号"列：
1. 提取对手证件号前6位（代表户籍所在地区划代码）
2. 将相同前6位的对手账户归为同一地域团伙
3. 身份证前6位相同意味着来自同一地区，在反洗钱场景中常与老乡团伙、地域性犯罪组织相关
4. 统计每个地域组的成员数和与主体的交易金额
5. 也可结合人员信息表中的"工作单位""单位地址"进行交叉验证

**子任务C3 — 基于对手开户银行的聚类分析**：

如交易明细中有"对手开户银行"字段：
1. 统计每个开户银行涉及的对手账户数和交易金额
2. 集中在同一银行/网点开立的多个对手账户可能提示有组织的开户行为

**子任务C4 — 基于交易关系和身份特征的团伙拓展**：

1. 同名账户关联：不同账户号但户名相同，视为同一人控制
2. 稳定资金关系：高频次、大金额的固定交易对手
3. 交易关键词关联：摘要中含"换汇""换钱"等关键词的对手账户
4. 关联人员信息：通过证件号匹配人员信息表，分析对手的工作单位、单位地址是否集中

**子任务C5 — 基于对手重合度的团伙划分** `[来源：技战法2"星链"、技战法3"三取四辨"]`：

通过比较不同账户的交易对手重合程度来识别同一团伙控制的账户：

1. 对每个账户，分别提取其出账对手集合和进账对手集合
2. 两两计算账户间的**出账对手重合度** = 交集对手数 / 并集对手数（Jaccard系数）
3. 阈值判定：
   - 重合度 ≥ 20%：视为可能由同一团伙控制 `[来源：技战法2"星链"]`
   - 重合度 ≥ 30%：视为高度疑似钱庄团伙 `[来源：技战法3"三取四辨"]`
4. 同时检查**进账对手重合度**，单向交易对手重合度 ≥ 30% 也视为团伙关联 `[来源：技战法3"三取四辨"]`
5. 将重合度超阈值的账户对用 Union-Find 归为同一团伙
6. 对重合度较高的账户对，生成**共同对手交易信息统计表**：列出每个共同对手分别与两个账户的交易笔数、金额、交易方向（进/出/双向），按合计金额降序排列，直观展示资金关联模式

**子任务C6 — 基于开户信息的团伙识别** `[来源：技战法8"比判分锁"]`：

如有账户信息表或人员信息表：
1. **预留手机号碰撞**：不同账户预留相同手机号码 → 同一人控制
2. **邮箱地址碰撞**：不同账户使用相同邮箱 → 同一人控制
3. **单位地址碰撞**：不同对手的单位地址相同或相近 → 可能为关联公司
4. **同一网点/ATM同时段操作** `[来源：技战法8"比判分锁"]`：同一交易网点、同一时段（30分钟内）出现不同账户操作 → 可能同一人操控多卡

**子任务C7 — 基于IP网段的团伙识别** `[来源：技战法10"热力图"]`：

区分IP地址类型进行更精确的团伙关联：
1. **企业专线IP**：固定分配给公司地址，同一IP出现不同账户操作 → 确定为同一地点控制
2. **家庭宽带IP**（动态IP）：运营商每24小时重新分配，需结合操作时间段综合分析：
   - 同一IP + 同一时段（24小时内）出现不同账户 → 同一地点操作
   - 跨天的相同IP不能直接认定为关联
3. **同一IP网段归类**：提取IP前三段（如192.168.1.*），同网段内的不同账户可视为同一局域网环境

**子任务C8 — 基于社群算法的团伙划分** `[来源：技战法11"剥洋葱"]`：

使用图算法对账户网络进行自动化团伙划分：
1. 以交易收付双方银行账户为节点，以交易金额和频次为边权重，构建资金关联网络
2. 使用Louvain社群检测算法（community模块）自动划分账户组
3. 每个社群即为一个独立的犯罪团伙候选
4. 计算各团伙的中介中心度（Betweenness Centrality），确认核心团伙
5. 使用最短路径算法，以核心团伙为起点，批量生成资金流转路径

**子任务C9 — 基于交易亲密度的团伙关联** `[来源：技战法9"智汇猎手"]`：

通过共同交易对手和相互交易频次补充团伙识别：
1. 两个账户拥有共同交易对手 ≥ 8次 → 关联
2. 首次发生10万元以上交易后，彼此存在相互交易 ≥ 3次 → 归为一组
3. 将满足条件的账户用 Union-Find 归为同一团伙

**子任务C10 — 工具账户 vs 核心账户区分** `[来源：技战法11"剥洋葱"、技战法13"四比对四锁定"]`：

对账户组中的银行账户进行功能分类：
1. **工具账户**：资金"集中转入分散转出""分散转入集中转出""快进快出不留余额"，无日常消费记录
2. **核心账户**：在工具账户间进行资金调拨的账户，极可能为团伙成员本人银行卡
3. **个人账户识别**：存在生活消费（如餐饮、超市、水电缴费）、理财投资、大额消费等特征
4. 不同犯罪类型的工具账户交易特征不同，可通过已确认案件样本训练分类模型

**子任务C11 — 共同反冻结测试团伙识别** `[来源：技战法12"平行拓线"]`：

将在同一时段（如24小时内）进行反冻结试探的不同账户归为同一团伙：
1. 多个账户在相近时间内均进行小额试探测试（≤20元）
2. 这些账户的试探时间窗口重叠
3. 共同进行反冻结测试 → 同一团伙批量检测账户状态

**子任务C12 — "五同"聚类分析** `[来源：技战法16"五定三比五同"]`：

从五个维度进行聚类分析识别团伙成员：
1. **同地址**：户籍所在地、商户注册地、结算卡开户地等地址聚类
2. **同轨迹**：住宿、铁路、航班等出行轨迹聚类（如数据支持）
3. **同设备**：交易IP/MAC聚类（与C1互补）
4. **同交易对象**：存在相同交易对手的账户聚类
5. **同操作**：临近时间内有共同转账、取现、柜台解冻等操作的账户聚类

**子任务C13 — 反冻结试探模式检测** `[来源：技战法8"比判分锁"]`：

检测是否存在"先小额试探、后大额转入"的反冻结测试行为：
1. 在进账记录中查找小额交易（≤ 20元）
2. 检查小额交易后24小时内是否有来自同一对手或同一团伙的大额交易（≥ 1万元）
3. 如存在此模式，将小额试探方标记为团伙账户
4. 阈值：小额 ≤ 20元，大额 ≥ 10000元，时间窗口 ≤ 24小时

**子任务C14 — 对手与涉案主体的团伙关系分析**：

团伙分析不能仅分析给出用户（涉案主体）之间的关系，还需分析交易对手与涉案主体之间的团伙关联。具体分析维度：

1. **对手与主体的设备关联**：检查对手账户是否与涉案主体在出账方向共享IP/MAC地址。如对手在交易明细中也作为"交易卡号"出现，提取其IP/MAC与主体的IP/MAC做碰撞比对
2. **对手与主体的资金关联强度**：计算每个对手与涉案主体之间的资金关联强度指标：
   - 交易金额占主体总交易额的比例
   - 交易频次（高频固定对手提示稳定关系）
   - 是否双向交易（双向且金额接近提示中转关系）
   - 交易时间跨度（长期稳定交易 vs 短期集中交易）
3. **对手之间的关联分析**：不仅看对手与主体的关系，还要分析对手之间是否存在关联：
   - 多个对手是否共享同一IP/MAC（通过交易明细中的对手记录分析）
   - 多个对手是否具有相同的证件号前6位（同地域）
   - 多个对手是否在同一时段与主体发生交易（协同操作）
   - 多个对手是否存在相互交易（通过交易明细中对手作为主体的记录分析）
4. **团伙关系图谱**：将上述分析结果汇总为团伙关系图谱，标注各节点（主体和对手）之间的关联类型和强度：
   - **核心成员**：与主体高频双向交易、共享设备、同地域的对手
   - **紧密关联**：与主体交易金额大、频次高的对手
   - **一般关联**：与主体有交易但频次低的对手
   - **外围成员**：仅与团伙其他成员交易、不直接与主体交易的对手（需多层穿透）

**数据缺失处理**：
- 如果交易明细中没有IP/MAC列：跳过C1，仅做C2-C7
- 如果没有对手证件号列：跳过C2，在报告中注明"因数据中缺少对手证件号信息，未进行地域关联分析"
- 如果没有人员信息表或账户信息表：跳过C6中的预留信息碰撞
- 如果数据中只有单一账户（无法比较多账户间的对手）：跳过C5
- 不要因为部分数据缺失而放弃整个团伙分析章节

### 阶段D：可疑特征量化与研判

**目标**：对前三阶段的发现进行量化评估，形成结论。

计算以下可疑指标（详见下方"可疑指标阈值"），逐项给出数值和判定结论，作为报告"可疑点分析"章节的依据。完成后根据指标组合匹配"经营模式识别规则"，推断可能的犯罪类型。

## 可疑指标与阈值

以下是核心可疑指标的计算方法和判定阈值。分析时逐项计算，每项给出具体数值和判定结论。

| 序号 | 指标名称 | 计算方法 | 正常范围 | 异常阈值 | 高度异常 |
| --- | --- | --- | --- | --- | --- |
| 1 | 收支平衡度 | abs(收入-支出) / (收入+支出) | > 20% | < 5% | < 1% |
| 2 | 现金交易占比 | 现金交易笔数 / 总交易笔数 | < 20% | > 50% | > 70% |
| 3 | 对手集中度(来源) | TOP3收入金额 / 总收入 | < 30% | > 40% | > 60% |
| 4 | 对手集中度(去向) | TOP3支出金额 / 总支出 | < 30% | > 40% | > 60% |
| 5 | 同名账户数 | 对手户名=主体户名的不同账户数 | 0 | >= 2 | >= 5 |
| 6 | 整额交易占比 | 整万金额交易笔数 / 总笔数 | < 15% | > 30% | > 45% |
| 7 | 快进快出天数占比 | 同日进出均>5万的天数 / 总交易天数 | < 5% | > 10% | > 20% |
| 8 | 资金周转率 | 交易总额 / 平均余额 | < 20 | > 50 | > 100 |
| 9 | 可疑关键词交易 | 摘要含"换汇/换钱/换币/兑换/换美金"的笔数 | 0 | >= 1 | >= 10 |
| 10 | 规避监控金额交易占比 `[来源：技战法1"四步"]` | 单笔金额在45000~49999元区间的交易笔数 / 总笔数 | < 1% | > 3% | > 5% |
| 11 | 小额试探交易数 `[来源：技战法1"四步"、技战法8"比判分锁"]` | 20元以下且随后24h内有同对手大额(≥1万)交易的笔数 | 0 | >= 2 | >= 5 |
| 12 | 通用摘要占比 `[来源：技战法8"比判分锁"]` | 摘要为"货款/往来款/采购款/投资/汇款"等通用词的笔数 / 总笔数 | < 30% | > 60% | > 80% |
| 13 | 账户休眠-激活次数 `[来源：技战法1"四步"、技战法8"比判分锁"]` | 休眠(≥30天无交易)后激活(日均≥5笔)的次数 | 0 | >= 1 | >= 3 |
| 14 | 日终余额趋零天数占比 `[来源：技战法1"四步"、技战法3"三取四辨"]` | 日终余额<1000元的天数 / 总交易天数 | < 20% | > 50% | > 70% |
| 15 | 对手重合度最大值 `[来源：技战法2"星链"、技战法3"三取四辨"]` | 任意两账户间的出账对手Jaccard重合度最大值 | < 10% | >= 20% | >= 30% |
| 16 | 反冻结试探次数 `[来源：技战法8"比判分锁"]` | 小额(≤20元)转入后24h内跟随大额(≥1万)转入的配对数 | 0 | >= 1 | >= 3 |
| 17 | 网银转账占比 `[来源：技战法1"四步"]` | 网银/手机银行渠道交易笔数 / 总笔数（需现金标志或渠道字段） | < 80% | > 95% | > 99% |
| 18 | 跨行转账不计成本 `[来源：技战法1"四步"]` | 出账中跨行转账占比（含手续费交易） | < 30% | > 60% | > 80% |
| 19 | 汇率匹配交易占比 `[来源：技战法9"智汇猎手"]` | 交易金额折算外币后趋近整数的笔数 / 总笔数 | < 5% | > 15% | > 30% |
| 20 | 一次性交易对手占比 `[来源：技战法9"智汇猎手"]` | 仅交易1-2次的对手数 / 总对手数 | < 30% | > 50% | > 70% |
| 21 | 非工作时间交易占比 `[来源：技战法9"智汇猎手"]` | 22:00-08:00交易笔数 / 总笔数 | < 10% | > 20% | > 30% |
| 22 | 账户活跃期短（月） `[来源：技战法9"智汇猎手"]` | 账户从首笔到末笔交易的月数（活跃期短提示工具账户） | > 6月 | ≤ 3月 | ≤ 1月 |
| 23 | 交易对手开户地分散度 `[来源：技战法9"智汇猎手"]` | 对手开户地涉及的省份数（分散度高提示钱庄） | < 5省 | > 10省 | > 20省 |
| 24 | 账户交易规模与身份匹配度 `[来源：技战法12"平行拓线"]` | 码牌商户/个体户的交易量与经营规模是否匹配 | 匹配 | 偏大 | 严重不匹配 |

补充指标（如数据支持，建议也计算）：
- 自身转账笔数和金额占比（存在且金额占比 > 5% 视为异常）
- 30分钟内进出配对数
- 非工作时间（22:00-08:00）交易占比（> 20% 视为异常，> 30% 视为高度异常）
- **地域集中度**：出账对手中，证件号前6位相同的人数占总对手数的比例（> 30% 视为异常）
- **对手开户银行集中度**：TOP1开户银行的对手账户数 / 总对手账户数（> 40% 视为异常）
- **交易金额与身份不匹配度** `[来源：技战法5"一梳二研"]`：结合人员信息表中的工作单位判断交易规模合理性（如无业人员月交易超百万）
- **钱庄利润率** `[来源：技战法7"比穿联汇"]`：(总进账 - 总出账) / 总进账，如在 0.5%~3% 区间视为典型钱庄抽佣比例
- **汇率匹配交易笔数** `[来源：技战法9"智汇猎手"]`：交易金额折算常见外币后趋近整数的笔数（> 10笔且涉及多个对手视为异常）
- **一次性交易对手占比** `[来源：技战法9"智汇猎手"]`：仅交易1-2次的对手数 / 总对手数（> 50% 视为异常）
- **交易对手开户地分散度** `[来源：技战法9"智汇猎手"]`：对手开户地涉及省份数（> 10省视为异常，提示全国性钱庄业务）
- **账户活跃期**：首笔至末笔交易时间跨度（≤ 2个月即休眠提示工具账户）
- **小额理财测试** `[来源：技战法9"智汇猎手"]`：账户中存在小额（如1元、10元）的理财购买/赎回操作，可能为测试账户可用性
- **敏感摘要关键词** `[来源：技战法13"四比对四锁定"]`：摘要含走私相关词汇（冻品、海鲜、鸡脚、猪副、牛副等）的交易笔数
- **人卡分离指标** `[来源：技战法9"智汇猎手"]`：交易IP/网银操作地与开户人户籍地/常住地不一致

## 多维评分模型 `[来源：技战法2"星链"]`

对筛选出的可疑账户进行多维度综合评分，按优先级排序。评分模型以16个维度设置阈值，总分越高可疑程度越高。

### 评分维度与分值

| 维度 | 评分规则 | 分值 | 数据来源 |
| --- | --- | --- | --- |
| 1. 收支平衡度 | < 1%: 3分; < 5%: 2分; < 20%: 1分 | 0~3 | 交易明细 |
| 2. 日终余额趋零 | > 70%: 3分; > 50%: 2分; > 30%: 1分 | 0~3 | 交易明细（余额列） |
| 3. 快进快出频率 | > 20%: 3分; > 10%: 2分; > 5%: 1分 | 0~3 | 交易明细 |
| 4. 资金周转率 | > 100: 3分; > 50: 2分; > 20: 1分 | 0~3 | 交易明细（余额列） |
| 5. 整额交易占比 | > 45%: 3分; > 30%: 2分; > 15%: 1分 | 0~3 | 交易明细 |
| 6. 规避监控金额 | > 5%: 3分; > 3%: 2分; > 1%: 1分 | 0~3 | 交易明细 |
| 7. 地域集中度 | > 50%: 3分; > 30%: 2分; > 15%: 1分 | 0~3 | 交易明细（对手证件号） |
| 8. 同姓氏对手占比 | TOP1姓氏 > 40%: 2分; > 25%: 1分 | 0~2 | 交易明细（对手户名） |
| 9. 对手年龄分布 | 18-25岁占比 > 50%: 2分; > 30%: 1分 | 0~2 | 交易明细（对手证件号推算） |
| 10. 可疑关键词 | ≥ 10笔: 3分; ≥ 1笔: 2分 | 0~3 | 交易明细（摘要） |
| 11. 通用摘要占比 | > 80%: 2分; > 60%: 1分 | 0~2 | 交易明细（摘要） |
| 12. 共享设备(IP/MAC) | 共享 ≥ 3个账户: 3分; ≥ 2个: 2分 | 0~3 | 交易明细（IP/MAC） |
| 13. 休眠-激活模式 | ≥ 3次: 3分; ≥ 1次: 2分 | 0~3 | 交易明细（时间序列） |
| 14. 汇率匹配交易 `[来源：技战法9"智汇猎手"]` | 占比 > 30%: 3分; > 15%: 2分; > 5%: 1分 | 0~3 | 交易明细（金额+汇率） |
| 15. 一次性对手占比 `[来源：技战法9"智汇猎手"]` | > 70%: 3分; > 50%: 2分; > 30%: 1分 | 0~3 | 交易明细（对手统计） |
| 16. 非工作时间交易 `[来源：技战法9"智汇猎手"]` | > 30%: 3分; > 20%: 2分; > 10%: 1分 | 0~3 | 交易明细（时间） |

### 优先级分级

| 级别 | 总分区间 | 说明 |
| --- | --- | --- |
| 一级（极高风险） | ≥ 25 | 立即重点关注，高度疑似犯罪账户 |
| 二级（高风险） | 18~24 | 需深入调查，多项指标异常 |
| 三级（中风险） | 10~17 | 需持续监测，部分指标异常 |
| 四级（低风险） | < 10 | 暂无明显异常，常规关注 |

**字段缺失处理**：缺失维度不参与评分，总分按实际参与维度数等比例调整。即：调整后总分 = 原始总分 / 实际参与维度数 × 16。

## 经营模式识别规则

根据可疑指标的组合，匹配以下犯罪模式。可能同时符合多种模式，逐一判断。

**地下钱庄 / 非法换汇**：
- 收支高度平衡（平衡度 < 5%）
- 现金交易占比高（> 50%）
- 对手集中度高
- 快进快出明显
- 存在"换汇/换钱"关键词
- 整额交易占比高

**对敲型地下钱庄** `[来源：技战法3"三取四辨"、技战法7"比穿联汇"、技战法9"智汇猎手"]`：
- 收支高度平衡（平衡度 < 1%）
- 存在比值 = 1.0 的虚开通道账户和比值 = 0.0 的钱庄指定账户
- 多层资金穿透后呈伞状分散结构
- 对手重合度 ≥ 30%
- 钱庄利润率在 0.5%~3% 区间
- 资金流末端向多级"人头卡"分散 `[来源：技战法7"比穿联汇"]`
- 交易金额非整数且带有角分，折算外币后趋近官方牌价整数倍 `[来源：技战法9"智汇猎手"]`
- 交易对手众多（>100个），重复率低（一次性对手占比 > 70%） `[来源：技战法9"智汇猎手"]`
- 当日流入流出比接近1:1，日终余额趋零（< 500元） `[来源：技战法9"智汇猎手"]`
- 账户开设后短期启用（1-2月），使用后休眠更换新账户 `[来源：技战法9"智汇猎手"]`
- 对手出现英文字母账户名、流入对手名称含"支付"字样 `[来源：技战法9"智汇猎手"]`
- 存在测试交易记录（小额验证交易） `[来源：技战法9"智汇猎手"]`

**非法支付结算（跑分平台）** `[来源：技战法4"一算二穿"、技战法5"一梳二研"]`：
- 交易频繁且金额大，与持卡人身份不符
- 多个账户共享IP/MAC
- 交易对手重叠固定
- 资金通过多级卡中转
- 账户存在休眠-激活交替模式
- 摘要多为通用词汇（货款、往来款等）

**非法资金归集转移**：
- 收支高度平衡
- 收入端小额多笔、支出端大额少笔（"小进大出"）
- 整额交易占比高
- 同名多账户控制

**电信诈骗资金分发**：
- 单向大额进入 + 快速分散小额出
- 账户活跃期短（通常数周到数月）
- 余额快速清零

**POS机洗钱** `[来源：技战法6"两查三拓三碰"]`：
- 小额试机交易后紧跟大额POS消费交易
- 同一银行卡短时间内多笔POS交易（一卡多刷）
- 交易摘要含POS消费类标识
- 资金快速转出至多个账户

**支付结算洗钱（话费充值型）** `[来源：技战法8"比判分锁"]`：
- 账户存在静默-爆发周期
- 小额入金碰撞测试（反冻结试探）
- 共享交易IP/MAC
- 交易摘要为货款、采购款、投资等通用词汇
- 多个空壳公司间资金腾挪

**骗税关联非法买卖外汇** `[来源：技战法7"比穿联汇"]`：
- 结汇后资金呈即进即出、全额流转特征
- 资金流末端呈伞状分散到"人头卡"
- 存在资金回流（A→B→C→A 环形路径）
- 利润率在典型汇率差区间（0.5%~3%）

**有组织团伙犯罪**：
- 多账户共享IP/MAC设备
- 同名多户控制
- 多层资金中转
- 对手证件号前6位地域高度集中
- 对手开户银行集中度高
- 对手重合度 ≥ 20% `[来源：技战法2"星链"]`
- 反冻结试探行为 `[来源：技战法8"比判分锁"]`

**码牌商户洗兑犯罪** `[来源：技战法16"五定三比五同"]`：
- 交易均为无卡非面对面交易（扫码支付，无线下刷卡）
- 单笔交易金额区间固定化（5千~5万）
- 商户使用时间短（易触发风控后更换）
- 上游进项资金来源复杂、对手众多、分布全国各地无地域特征
- 同一银行卡极少重复消费（唯一性强，大多仅交易1次）
- 涉电诈一级卡碰撞命中率高
- 商户户主及关系人有反诈平台查控/冻结记录

**服务偷渡型地下钱庄** `[来源：技战法12"平行拓线"]`：
- 偷渡人员账户存在境外消费/ATM取现记录，次数多且时间跨度 > 3个月
- 本人无出境记录或从边境出境，目的地为柬埔寨、菲律宾、越南等敏感地区
- 钱庄账户特征：即进即出、对手众多且不特定、资金不过夜、敏感摘要
- 商户结算账户交易量巨大但与开户人现实状况不符
- 不同姓名的银行账户使用同样MAC码

**走私型洗钱犯罪** `[来源：技战法13"四比对四锁定"]`：
- 交易摘要含走私相关关键词（冻品、海鲜、鸡脚、猪副、牛副等）
- 涉案人员活动轨迹在沿海、边境一带或外贸发达地区
- 工具账户无日常消费、快进快出，团伙成员使用关系人账户且有明显地缘特征
- 在政策宽松地区进行大额取现或雇佣专门取现人员
- 资金多次流转后回归实名账户，短时间内多渠道大额取现
- 佣金通过第三方支付工具小额分发

**涉游戏点卡地下钱庄** `[来源：技战法9"智汇猎手"]`：
- 账户交易关联游戏点卡平台或虚拟资产交易
- 存在境外销售网站关联的资金入账
- 资金通过点卡购买-销售链条实现跨境对敲
- 支付结算型钱庄将犯罪资金混入点卡交易，用境外点卡切断资金链

**市场采购贸易洗钱** `[来源：技战法9"智汇猎手"]`：
- **高值低报型**（骗税关联）：实际出口货值低报，截留境外多余货款作为外汇出售给骗税企业
- **低值高报型**（地下钱庄关联）：实际出口货值高报，虚增外汇来源于钱庄境外资金池，利用市场采购渠道结汇洗白

匹配到模式后，在报告中按"四层模型"描述经营模式：
1. **资金归集层**（收款阶段）：上游账户归集客户资金
2. **资金中转层**（结算阶段）：核心账户整合与分配
3. **资金分配层**（分配阶段）：向下游分发
4. **变现层**（付款阶段）：现金取款或购汇

## 资金穿透规则 `[来源：技战法2"星链"、技战法7"比穿联汇"]`

资金穿透是追踪资金上下游流向的核心环节，遵循以下规则：

### 穿透层数

至少追踪 **3层** 资金流向 `[来源：技战法2"星链"]`：
- 第1层：涉案账户的直接交易对手
- 第2层：直接对手的交易对手（如数据中包含对手自身的交易明细）
- 第3层：第2层对手的对手
- 如数据仅含主体账户交易明细，则只做1层分析，注明数据范围限制

### 穿透分类 `[来源：技战法2"星链"]`

对穿透出的每一层账户按资金方向分为三类：
1. **单向流入类**：仅向涉案账户转入，无反向交易 → 可能为上游犯罪资金
2. **双向交易类**：与涉案账户既有进又有出 → 可能为平行钱庄或拆借关系
3. **单向流出类**：仅从涉案账户接收转出 → 可能为下游洗钱通道

### 伞状分散结构检测 `[来源：技战法7"比穿联汇"]`

检测资金流末端是否呈伞状分散：
- 一个账户在短时间内（如24小时内）向 ≥ 5个不同对手分散转出
- 分散转出的各笔金额相近（标准差/均值 < 0.3）
- 判定为向"人头卡"分散转账的伞状结构

### 资金回流检测 `[来源：技战法7"比穿联汇"]`

检测资金是否形成闭环：
- A→B→C→A 的环形资金流
- 方法：对穿透出的3层账户，检查是否存在资金回流到第1层或主体账户
- 回流提示资金池操作或对敲行为

### 图算法辅助穿透 `[来源：技战法11"剥洋葱"]`

利用图算法增强资金穿透分析效率：

1. **资金关联网络构建**：以账户为节点、交易为边（权重=交易金额），使用 networkx 的 `from_pandas_edgelist` 方法构建有向图
2. **社群划分**：使用 Louvain 算法（`community.best_partition`）按交易频次权重自动划分账户组，每个社群为独立犯罪团伙候选
3. **中介中心度排序**：使用 `load_centrality` 计算各团伙在整个网络中的中介中心度，中心度最高的为核心团伙
4. **最短路径资金链**：使用 `shortest_path` 以核心团伙为起点，批量生成到其他团伙的资金流转路径
5. **团伙间净流向分析**：计算团伙间的资金净流向（流入-流出），确定各团伙在犯罪链条中的角色分工

### 接收/发放/取现三分类 `[来源：技战法14"五维五步"]`

对犯罪团伙控制的银行卡按职能进行三分类：
1. **接收账户**：主要用于接收上游资金，进账远大于出账
2. **发放账户**：主要用于向下游分发资金，出账远大于进账
3. **取现账户**：主要用于ATM或柜台取现，现金支出占比高
- 取现规律特征：资金池余额保持在一定范围用于周转，长期定点城市ATM及柜台取现
- 取现部分占换汇总额的比例可用于估算非法换汇规模

### 利润率计算 `[来源：技战法7"比穿联汇"]`

钱庄利润率 = (总进账 - 总出账) / 总进账
- 正常商业利润率通常 > 5%
- 钱庄典型抽佣比例为 0.5%~3%
- 如利润率落入此区间且其他钱庄特征吻合，进一步佐证钱庄性质

## 常见问题处理

分析过程中遇到问题时参考以下指引，不要卡住。

### 数据列名不匹配

不同系统导出的交易数据列名差异很大。先打印列名再适配：

```python
print(df.columns.tolist())
```

### Excel文件过大或读取失败

```python
# 先探查文件结构
df = pd.read_excel('file.xlsx', nrows=5)
print(f"列名: {df.columns.tolist()}")
print(f"数据类型: {df.dtypes}")

# 如果文件过大（>100MB），考虑分块处理
# 或指定只读需要的列
usecols = ['交易时间', '交易金额', '收付标志', '交易对手账卡号', '对手户名',
           'IP地址', 'MAC地址', '对手证件号', '对手开户银行', '交易发生地']
df = pd.read_excel('file.xlsx', usecols=usecols)
```

### 代码运行报错

排查步骤：
1. `print(df.head())` — 确认数据长什么样
2. `print(df.dtypes)` — 确认列的数据类型（金额是否为数值型、时间是否已转换）
3. `print(df['目标列'].unique()[:20])` — 确认列的实际取值
4. 根据以上信息调整代码

常见问题：
- 金额列含逗号或货币符号：`df['金额'] = pd.to_numeric(df['金额'].astype(str).str.replace(',','').str.replace('¥',''), errors='coerce')`
- 时间列格式混乱：`pd.to_datetime(df['时间'], format='mixed', dayfirst=False)`
- 分组统计时NaN导致报错：先 `.dropna(subset=['目标列'])` 再分组

### 分析结果不符合预期

- **收支严重不平衡**（如只有进没有出）：检查收付标志列的取值是否正确识别，可能是"借/贷"而非"进/出"
- **对手全部为NaN**：可能现金交易没有对手信息，属正常现象，在报告中说明
- **团伙划分结果只有1个大团伙**：检查是否有某个IP/MAC被大量账户共享（如公共WiFi），考虑过滤掉关联账户数超过50的IP
- **年度统计金额与总额对不上**：检查是否有交易金额为0的记录或异常值
- **交易笔数与预期不符**：检查是否已过滤"交易是否成功" != 1 的失败交易。**如果过滤后数据量大幅减少（如过滤掉超过50%），说明过滤条件有误**——实际数据中成功标识可能不是1，而是"成功"、True、"Y"等，应改为仅过滤明确为失败的记录
- **大量数据被意外过滤**：**绝对不要**对"交易卡号"列做任何格式校验（如要求纯数字、长度>=16位、非空等）。卡号为空是正常现象（有些账户只有账号没有卡号），不应导致记录被丢弃。如果主体账户数量统计时发现卡号有空值，应使用"交易户名"或"交易账号"来识别主体，而不是过滤掉卡号为空的记录
- **对手重合度全部为0** `[来源：技战法2"星链"]`：检查数据中是否只有单一账户，对手重合度需要至少两个主体账户才有意义
- **休眠-激活检测无结果** `[来源：技战法1"四步"]`：检查交易时间跨度，短期数据可能无法体现休眠-激活周期

### 数据量过少（<100笔）

- 年度趋势改为按季度或月度统计
- 金额分布合并为3个区间（小额/中额/大额）
- 团伙分析简化为仅做同名账户和交易关系分析
- 快进快出改为逐笔检查而非统计天数
- 多维评分模型中降低阈值或减少维度
