# 经侦分析能力 Skill

## 概述
本skill用于指导进行经济犯罪侦查数据分析，涵盖资金流向、电子支付、通信数据、税务数据等多维度的分析方法论。

## 二、数据源类型与字段映射

### 2.1 资金交易表
核心字段：
- **交易方信息**：交易卡号、交易账号、交易户名
- **对手方信息**：对手卡号、对手账号、对手户名
- **交易属性**：收付标志(进/出/收/付/存/取)、交易时间、交易金额
- **扩展信息**：证件号码、摘要、IP地址、MAC地址

收付标志映射：
- 进账标识：进、收、入
- 出账标识：出、付、取、存

### 2.2 通话记录表
核心字段：
- 主叫号码、被叫号码、通话时长、通话时间
- 通话类型：主叫、被叫

### 2.3 支付宝交易记录表
核心字段：
- 买家ID、卖家ID、交易金额、交易时间
- 买家姓名、卖家姓名、收货地址

### 2.4 财付通交易记录表
核心字段：
- 用户ID、对手ID、交易金额、交易时间
- 交易类型(收/支)、支付类型

### 2.5 税票数据表
核心字段：
- 购方识别号、销方识别号、金额、开票日期

## 三、核心分析方法论

### 3.1 资金流向分析

#### 3.1.1 资金来源分析
**分析目的**：识别被调查账户的主要资金来源

**核心分析逻辑**：
1. 筛选进账交易（收付标志为进/收/入）
2. 按交易户名和对手户名分组统计
3. 计算每组的转账总金额、转账总笔数
4. 按金额阈值过滤，按金额降序排列

**关键指标**：
- 转账总金额、转账总笔数
- 转入金额、转入笔数
- 转出金额、转出笔数
- 首次/最后交易时间

#### 3.1.2 资金去向分析
**分析目的**：识别被调查账户的主要资金去向

**核心分析逻辑**：
1. 筛选出账交易（收付标志为出/付/取/存）
2. 按对手卡号或对手户名分组统计
3. 计算每组的转出总金额、转出总笔数
4. 按金额阈值过滤，按金额降序排列

### 3.2 可疑交易识别

#### 3.2.1 即进即出分析
**分析目的**：识别快速进出的可疑账户（洗钱特征）

**识别逻辑**：
1. 分别提取进账和出账记录
2. 按账户维度合并统计进出情况
3. 识别进出金额接近、时间间隔短的账户

**关键参数**：
- 单笔金额阈值：50,000元
- 差额交易金额阈值：1,000元
- 进账/出账金额比例范围

#### 3.2.2 过渡账卡号分析
**分析目的**：识别作为资金中转的账户

**识别标准**：
- 进出金额基本平衡（差额小）
- 交易频繁
- 资金停留时间短

**关键参数**：
- 交易总金额不低于：10,000元
- 交易净额不超过：10,000元

#### 3.2.3 可疑资金对手分析
**分析目的**：识别与被调查账户有可疑交易往来的对手

**分析维度**：
- 交易频率
- 交易金额
- 进出差值
- 首次/最后交易时间

### 3.3 资金模式识别

#### 3.3.1 吸金账户识别
**识别特征**：
- 转入总金额/转出总金额 > 阈值（如5）
- 转入总金额 > 最低阈值（如10,000元）
- 转入笔数/转出笔数 > 阈值（如5）
- 转入笔数 > 最低阈值（如10）

**典型场景**：集资账户、诈骗收款账户

#### 3.3.2 集中转入分散转出
**识别特征**：
- 多人转入，转出给多人
- 转入/转出金额比值在特定范围(0.6-1.4)
- 转入总金额超过阈值
- 转入笔数/转出笔数比值高（如>6）

**典型场景**：洗钱中转账户

#### 3.3.3 分散转入集中转出
**识别特征**：
- 多人转入，集中转出给少数人
- 转入笔数多，转出笔数少
- 转出金额集中

**典型场景**：集资或诈骗账户

### 3.4 关联分析

#### 3.4.1 群组分析
**分析目的**：识别有共同资金往来的账户群组

**分析逻辑**：
1. 按群组标签分组
2. 统计群组内的账户数量
3. 计算群组总交易金额
4. 排除账户自身的交易

**输出指标**：
- 群组名称、成员列表、对手账户
- 群组成员数、涉及对手数
- 交易总金额、总笔数
- 进出差值、首末交易时间

#### 3.4.2 共同对手分析
**分析目的**：找出两个调查对象共同的交易对手

**分析逻辑**：
1. 获取调查对象1的所有交易对手
2. 获取调查对象2的所有交易对手
3. 通过关联找出共同对手
4. 排除知名机构（银行、支付平台等）

**排除关键词**：
银行、支付、财付通、支付宝、微信、保险、证券、基金、电信、移动、联通、电力、燃气、水务、医院、学校、平台、电商等

### 3.5 大额交易分析

**分析维度**：
- 按账卡号统计大额交易
- 按户名统计大额交易
- 按对手ID统计大额交易
- 按用户ID统计大额交易

**核心指标**：
- 大额交易总金额
- 大额交易笔数
- 最大单笔金额
- 进出差值

### 3.6 通信分析

#### 3.6.1 通话来源/去向分析
**核心指标**：
- 主叫次数、被叫次数
- 主叫时长、被叫时长
- 首次/最后通话时间

**关键参数**：
- 通话时长总和不低于：10分钟

#### 3.6.2 对方号码关联度
**分析目的**：识别频繁联系的号码

**分析维度**：
- 通话频率
- 通话总时长
- 通话时间段分布

## 六、分析流程指南

### 6.1 推荐分析顺序

```
1. 交易概览 → 了解整体数据规模
      ↓
2. 资金来源/去向 → 建立资金流向框架
      ↓
3. 可疑识别(即进即出/过渡账/可疑对手) → 锁定重点账户
      ↓
4. 模式识别(吸金/集中分散) → 判断行为特征
      ↓
5. 关联分析(群组/共同对手) → 扩展调查范围
      ↓
6. 电子支付/通信/税务 → 多维度验证
```

### 6.2 分析报告结构
1. **数据概况**：涉及的账户数、交易笔数、交易总额
2. **资金流向图**：主要资金来源和去向
3. **可疑账户清单**：按可疑程度排序
4. **关联关系图**：账户之间的资金往来关系
5. **建议措施**：下一步调查方向

## 八、使用指南

### 8.1 分析指令示例
```
# 资金流向分析
请分析以下账户的资金来源和去向，重点关注金额超过10000元的交易

# 可疑识别
请识别数据中存在即进即出特征的账户

# 关联分析
请分析账户A和账户B之间是否存在共同交易对手

# 群组分析
请按照交易关联关系，识别可能存在的账户群组

# 模式识别
请识别数据中的吸金账户和过渡账户
```

### 8.2 注意事项
1. 分析前需确认数据完整性
2. 阈值参数应根据案件具体情况调整
3. 排除正常金融机构交易
4. 结合多种分析维度交叉验证
5. 关注异常时间段的交易行为
6. 注意区分个人账户和对公账户

### 8.3 分析结果解读
- **即进即出账户**：可能是洗钱中转账户
- **吸金账户**：可能是集资或诈骗收款账户
- **集中分散账户**：可能是洗钱组织账户
- **群组账户**：可能是有组织的犯罪团伙
- **共同对手**：可能是资金汇集点或分发点
