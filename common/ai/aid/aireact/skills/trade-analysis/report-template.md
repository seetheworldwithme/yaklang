# 商贸类经济犯罪资金分析报告模板

以下为十章结构的报告模板。每章包含**必须覆盖的内容项**和**写作风格指引**。根据实际数据填入分析结果，措辞和详略可自由调整。

---

## 一、基本情况

### （一）案件背景

简要描述案件来源、涉案主体、涉嫌罪名。如用户未提供案件背景，根据数据分析推断犯罪类型。

**写作指引**：用2-3句话概括案件基本面貌，如"某公司法定代表人张某某涉嫌合同诈骗，于2023年1月至2024年6月间，以承接工程为名收取多家企业预付款后转移资金、逃避履约。现对其名下银行账户交易流水进行资金分析。"

### （二）账户基本信息

以表格展示涉案账户的基础属性。区分企业对公账户和个人账户。

**涉案账户信息表**（数据来源：账户信息表）：

| 项目 | 内容 |
| --- | --- |
| 客户名称 | {账户开户名称} |
| 账户性质 | {个人账户/企业对公账户} |
| 涉案账户 | {交易卡号} |
| 证件号码 | {开户人证件号码} |
| 开户时间 | {账号开户时间} |
| 开户银行 | {账号开户银行} |
| 开户网点 | {开户网点} |
| 账户类型 | {账户类型} |
| 账户状态 | {账户状态} |
| 当前余额 | {账户余额} |

> 如有多个涉案账户，逐一列出。标注账户间关系（如"张某某为A公司法定代表人"）。

**企业基本信息表**（如有企业工商信息）：

| 项目 | 内容 |
| --- | --- |
| 企业名称 | {企业名称} |
| 统一社会信用代码 | {代码} |
| 法定代表人 | {法人} |
| 注册资本 | {注册资本} |
| 成立日期 | {日期} |
| 经营范围 | {范围} |
| 经营状态 | {状态} |

**写作指引**：简洁列表，一目了然。如有多个涉案账户（个人+企业），先列企业账户再列个人账户，并说明账户间关系。

### （三）交易概况

以表格展示总体交易数据。

| 项目 | 笔数 | 金额（元） | 占比 | 涉及对手账户数 |
| --- | --- | --- | --- | --- |
| 收入 | {收入笔数} | {收入金额} | {收入占比} | {收入对手账户数} |
| 支出 | {支出笔数} | {支出金额} | {支出占比} | {支出对手账户数} |
| 合计 | {总笔数} | {总金额} | 100% | - |

**写作指引**：表格后用1-2句话概括核心发现。如有过滤失败交易，注明"原始数据共X笔，过滤失败交易Y笔后，有效交易Z笔"。

### （四）交易结构特点

用"一是……二是……三是……"的递进结构，归纳3-5个核心特征。

**必须覆盖**：
- 收支比例与平衡特征
- 个人/企业交易比例（对公vs对私）
- 现金交易占比（如有数据）
- 日均交易密度
- 交易金额分布特征
- 交易摘要关键词特征（如"工程款""保证金""货款"等高频词）
- 余额波动特征（如有数据）

**写作指引**：每个特征点用1-3句话，先说数据，再给判断。例如："一是对公转对私比例异常。在全部支出交易中，向个人账户转出金额占总支出的X%，远超正常企业经营的对私支出比例，具有典型的资金转移特征。"

## 二、资金交易情况

### （一）总体概况

扩展第一章的交易概况，增加更多维度的统计。

**必须包含的表格**：
- 年度/月度交易统计表（按时间分列收入/支出的笔数、金额、对手主体数）
- 金额分布表（按金额区间分列收入/支出的笔数）

年度统计表参考格式：

| 年度 | 收入笔数 | 收入金额 | 收入对手数 | 支出笔数 | 支出金额 | 支出对手数 |
| --- | --- | --- | --- | --- | --- | --- |
| 2022 | {数据} | {数据} | {数据} | {数据} | {数据} | {数据} |
| ... | | | | | | |

**写作指引**：在表格前后加简要文字说明趋势。如交易量在某个时间段骤增或骤减，可能与犯罪行为的启动或收手有关，需要特别指出。

### （二）交易摘要关键词分析

对交易摘要字段进行关键词统计，识别业务类型分布。

**必须包含**：
- 高频关键词TOP20列表及对应的交易笔数/金额
- 按业务类型分类统计（如工程款、保证金、货款、投资、借款、转账等）
- 可疑关键词标记（如"好处费""回扣""佣金"等）

**写作指引**：交易摘要是还原业务真实面貌的重要线索。如发现摘要中频繁出现"保证金"等词，但对手企业并非正常业务合作方，需要重点标注。

### （三）现金交易情况

如数据中有现金标志，单独分析。

**必须包含**：
- 现金收入/支出的笔数、金额、占比
- 现金交易的时间分布和金额分布
- 大额现金交易（单笔>5万元）明细

**写作指引**：商贸犯罪中现金交易常用于规避监管。如现金交易集中在特定时间段（如开标前后），需关联分析。

### （四）交易地理分布

如有"交易发生地"字段，分析交易的地域分布。

**写作指引**：如无交易发生地数据，注明跳过。

### （二）基于企业关联的穿透分析

通过股东/法人/高管身份重叠识别关联企业群。

**必须包含**：
- 同一法人/股东控制的多家企业列表
- 企业间资金往来统计
- 企业关联图谱描述

**写作指引**：如无企业工商信息，基于交易明细中出现的企业户名和交易关系进行推断。标注同一自然人（通过证件号匹配）在不同企业账户中出现的情况。

如交易明细中有"对手证件号"字段，提取前6位进行地域聚合。

**写作指引**：如无对手证件号，注明原因并跳过。

### （四）基于交易关系的团伙拓展

**必须包含**：
- 同名多户情况
- 高频稳定交易关系
- 可疑关键词关联
- 通过人员信息关联发现的线索

### （五）团伙组织架构

综合以上分析，推断团伙的组织结构和分工。

**写作指引**：
- 合同诈骗场景：按"老板—马仔—外围壳公司"结构描述

- 串通投标场景：按"操控人—陪标公司—围标团队—内部人员"结构描述
- 行受贿场景：按"行贿方—中间人/白手套—受贿方"结构描述

## 七、可疑点分析

逐项列出每个可疑特征，每项包含：具体数据 + 与阈值的对比 + 结论判断。

**建议格式**："一是{可疑特征名}。{具体数据描述}，{与阈值比较}，{判断结论}。"

**必须覆盖的可疑特征**（根据犯罪场景和数据实际情况筛选，至少包含6项以上）：

**通用可疑特征**：
1. 交易收支平衡或严重失衡
2. 现金交易占比异常
3. 资金来源/去向高度集中
4. 同名多户控制
5. 整额交易占比异常
6. 快进快出特征
7. 对公转对私比例异常
8. 多账户共享设备（IP/MAC）
9. 非工作时间交易集中

**合同诈骗可疑特征**：
10. 合同款到账后迅速转出
11. 签约前账户余额极低
12. 资金大量挪作非合同用途
13. 违约后加速转移资金

**职务侵占可疑特征**：
14. 周期性小额异常转出
15. 偶发异常对手集中
16. 从企业账户向个人账户异常流出

**行受贿可疑特征**：
17. 行受贿双方存取款时间/金额碰撞
18. 受贿方出现与收入不符的存款
19. 存在第三方中转的利益输送

**串通投标可疑特征**：
20. 保证金同源
21. 工程款集中流向第三方
22. 存在疑似好处费支出
23. 不同公司账户出现同时同额交易

**写作指引**：数据说话，先摆事实再下结论。无数据支撑的特征不要硬写。

## 八、经营模式与涉案资金穿透研判

### （一）犯罪模式判定

基于前七章的发现，匹配犯罪模式（见SKILL.md中的犯罪模式识别规则），明确判定犯罪类型和作案手法。

**写作指引**：用清晰的逻辑链条说明："综合以上分析，涉案账户具有XX犯罪的典型特征：一是……二是……三是……"

### （二）资金流向链条

用"四层模型"描述完整的犯罪资金流向：

1. **资金来源层**：资金从何而来（合同款/投标保证金/公司营收等）
2. **核心操作层**：涉案账户如何处理资金（归集/拆分/中转/对冲等）
3. **资金去向层**：资金流向何处（关联个人/壳公司/第三方等）
4. **变现/消耗层**：资金最终用途（现金取款/购房购车/消费/再投资等）

以资金流向链条形式展示：
```
[来源层] 合作企业A合同款 ──→ [操作层] 涉案公司对公账户 ──→ [去向层] 法人个人账户 ──→ [消耗层] 购房/消费
[来源层] 合作企业B预付款 ──↗                              ↘ [去向层] 关联人张某账户 ──→ [消耗层] 现金取款
```

**写作指引**：结合具体交易数据描述每一层，避免空泛概括。

### （三）涉案资金穿透

**必须包含**：
- 主要资金来源的上游追踪
- 主要资金去向的下游追踪
- 估算涉案资金总规模

**写作指引**：如交易明细中不包含对手账户自身的交易记录，只做一层分析，注明"受数据范围限制，仅追踪至第一层上下游"。

## 格式规范

1. **报告标题**：`{户名}_{账户号后4位}_商贸犯罪资金分析报告` 或 `{案件名称}_资金分析报告`
2. **数值格式**：金额保留2位小数并加千分位（如 1,234,567.89 元），百分比保留1-2位小数
3. **表格**：重要数据必须以表格展示，不要纯文字堆砌
4. **章节编号**：使用"一、二、三……"作为一级标题，"（一）（二）（三）……"作为二级标题
5. **段落结构**：分析类段落采用"一是……二是……三是……"的递进结构
6. **语言风格**：正式、客观、专业。使用"该账户""涉案账户""涉案企业"
7. **数据缺失说明**：如因数据字段缺失而跳过某项分析，必须在对应位置注明原因
8. **专项分析选择**：根据实际犯罪场景选择五-1至五-6中的对应章节，不需要全部写，但至少写一个。涉及公司资金转个人账户的场景必须包含多层资金穿透分析（五-6）
9. **脱敏处理**：报告中涉及的姓名、身份证号、银行卡号等敏感信息需适当脱敏（如"张某某""6228****1234"）
