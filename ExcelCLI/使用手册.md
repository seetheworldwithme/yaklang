# ExcelCLI 使用手册

**版本**: 0.1.0  
**定位**: 经侦 Excel/CSV 原生分析 CLI

---

## 一、整体工作流

ExcelCLI 采用 **导入 → 映射 → 标准化 → 分析** 的四步工作流：

```
Excel/CSV 文件  →  import  →  SQLite 数据库
                              ↓
                           map  →  字段映射 JSON
                              ↓
                        normalize  →  标准表
                              ↓
                    analyze / query / transactions
```

涉税分析有独立的 **tax** 子工作流：

```
数据库  →  tax map  →  涉税映射 JSON
             ↓
        tax normalize  →  标准涉税表
             ↓
   tax analyze / tax invoices
```

---

## 二、命令总览

| 命令 | 说明 |
|---|---|
| `excelcli import` | 导入 Excel/CSV 到 SQLite |
| `excelcli inspect` | 查看数据库表结构和样例 |
| `excelcli map` | 生成银行流水字段映射 |
| `excelcli normalize` | 标准化为 bank_transactions 表 |
| `excelcli analyze fund` | 基础资金分析 |
| `excelcli query` | 执行自定义 SQL 查询 |
| `excelcli transactions` | 交易流水多维筛选 |
| `excelcli tax map` | 涉税表自动识别与映射 |
| `excelcli tax normalize` | 涉税表标准化 |
| `excelcli tax analyze` | 涉税风险概览分析 |
| `excelcli tax invoices` | 发票明细筛选 |

## 三、命令详解

### 1. `excelcli import` — 导入数据

将 xls/xlsx/csv 文件原样导入 SQLite 数据库。

```bash
excelcli import <INPUT> --case-id <案件编号> --db <数据库路径> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<INPUT>` | ✅ | 输入文件路径（支持 .xls / .xlsx / .csv） |
| `--case-id` | ✅ | 案件编号，用于区分不同案件 |
| `--db` | ✅ | SQLite 数据库输出路径 |
| `--verify` | ❌ | 导入后校验数据完整性（默认关闭） |
| `--encoding` | ❌ | 指定 CSV 文件编码（如 `gbk`、`utf-8`） |

**示例**：

```bash
excelcli import 交易流水.xlsx --case-id case001 --db data.db
excelcli import 数据.csv --case-id case001 --db data.db --encoding gbk --verify
```

---

### 2. `excelcli inspect` — 查看表结构

查看数据库中所有表的结构和样例数据。

```bash
excelcli inspect <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--sample` | ❌ | 每张表显示的样例行数（默认 3） |
| `--json` | ❌ | 以 JSON 格式输出 |

**示例**：

```bash
excelcli inspect data.db
excelcli inspect data.db --sample 5 --json
```

---

### 3. `excelcli map` — 生成字段映射

根据原始表的列名，自动生成银行流水标准字段映射。

```bash
excelcli map <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--profile` | ❌ | 映射配置模板（默认 `bank-transaction`） |
| `--out` | ❌ | 映射结果输出到 JSON 文件 |
| `--json` | ❌ | 以 JSON 格式输出到终端 |

**示例**：

```bash
excelcli map data.db --out mapping.json
excelcli map data.db --json
```

---

### 4. `excelcli normalize` — 数据标准化

根据映射文件，将原始表标准化为 `bank_transactions` 标准表。

```bash
excelcli normalize <DB> --mapping <映射文件>
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--mapping` | ✅ | 字段映射 JSON 文件路径 |

**示例**：

```bash
excelcli normalize data.db --mapping mapping.json
```

---

### 5. `excelcli analyze fund` — 资金分析

对标准化后的银行流水进行基础资金分析。

```bash
excelcli analyze fund <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--json` | ❌ | 以 JSON 格式输出 |

**示例**：

```bash
excelcli analyze fund data.db
excelcli analyze fund data.db --json
```

---

### 6. `excelcli query` — SQL 查询

在数据库上执行只读 SQL 查询，适合自定义分析。

```bash
excelcli query <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--sql` | ❌ | 直接传入 SQL 语句 |
| `--file` | ❌ | 从文件读取 SQL 语句 |
| `--limit` | ❌ | 返回结果行数上限（默认 100） |
| `--json` | ❌ | 以 JSON 格式输出 |
| `--csv` | ❌ | 以 CSV 格式输出 |

> `--sql` 和 `--file` 二选一，都不传则返回提示。

**示例**：

```bash
excelcli query data.db --sql "SELECT * FROM bank_transactions LIMIT 10"
excelcli query data.db --file analysis.sql --limit 500 --csv
excelcli query data.db --sql "SELECT account, SUM(amount) FROM bank_transactions GROUP BY account" --json
```

---

### 7. `excelcli transactions` — 交易流水筛选

对标准化后的银行流水进行多维度筛选。

```bash
excelcli transactions <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--account` | ❌ | 按账号筛选 |
| `--counterparty` | ❌ | 按对手方名称筛选 |
| `--direction` | ❌ | 按交易方向筛选（如 收/支） |
| `--min-amount` | ❌ | 最小金额 |
| `--max-amount` | ❌ | 最大金额 |
| `--start` | ❌ | 起始日期 |
| `--end` | ❌ | 截止日期 |
| `--keyword` | ❌ | 关键词模糊搜索 |
| `--limit` | ❌ | 返回结果行数上限（默认 100） |
| `--json` | ❌ | 以 JSON 格式输出 |
| `--csv` | ❌ | 以 CSV 格式输出 |

**示例**：

```bash
excelcli transactions data.db --account "622848123456" --min-amount 10000
excelcli transactions data.db --counterparty "张三" --start 2024-01-01 --end 2024-06-30 --csv
excelcli transactions data.db --direction 支出 --keyword "转账" --limit 200
```

---

### 8. `excelcli tax map` — 涉税表映射

自动识别数据库中的发票、税务登记、工商信息等涉税相关表，并生成映射。

```bash
excelcli tax map <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--out` | ❌ | 映射结果输出到 JSON 文件 |
| `--json` | ❌ | 以 JSON 格式输出到终端 |

**示例**：

```bash
excelcli tax map data.db --out tax_mapping.json
```

---

### 9. `excelcli tax normalize` — 涉税表标准化

根据涉税映射生成标准表和标准视图。

```bash
excelcli tax normalize <DB> --mapping <映射文件>
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--mapping` | ✅ | 涉税映射 JSON 文件路径 |

**示例**：

```bash
excelcli tax normalize data.db --mapping tax_mapping.json
```

---

### 10. `excelcli tax analyze` — 涉税风险分析

对标准化后的涉税数据进行风险概览分析。

```bash
excelcli tax analyze <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--taxpayer` | ❌ | 按纳税人名称过滤 |
| `--start` | ❌ | 起始日期 |
| `--end` | ❌ | 截止日期 |
| `--top` | ❌ | 显示 Top N 风险项（默认 10） |
| `--json` | ❌ | 以 JSON 格式输出 |

**示例**：

```bash
excelcli tax analyze data.db
excelcli tax analyze data.db --taxpayer "某某公司" --start 2024-01-01 --end 2024-12-31 --top 20
```

### 11. `excelcli tax invoices` — 发票明细筛选

对标准化后的发票数据进行多维度筛选。

```bash
excelcli tax invoices <DB> [选项]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `<DB>` | ✅ | SQLite 数据库路径 |
| `--role` | ❌ | 按发票角色筛选（如 销方/购方） |
| `--taxpayer` | ❌ | 按纳税人名称筛选 |
| `--counterparty` | ❌ | 按对手方名称筛选 |
| `--invoice-type` | ❌ | 按发票类型筛选 |
| `--start` | ❌ | 起始日期 |
| `--end` | ❌ | 截止日期 |
| `--min-amount` | ❌ | 最小金额 |
| `--max-amount` | ❌ | 最大金额 |
| `--keyword` | ❌ | 关键词模糊搜索 |
| `--limit` | ❌ | 返回结果行数上限（默认 100） |
| `--json` | ❌ | 以 JSON 格式输出 |
| `--csv` | ❌ | 以 CSV 格式输出 |

**示例**：

```bash
excelcli tax invoices data.db --taxpayer "某某公司" --min-amount 50000 --csv
excelcli tax invoices data.db --role 销方 --invoice-type 增值税专用发票 --limit 500
```

## 四、典型完整流程示例

### 银行流水分析

```bash
# Step 1: 导入
excelcli import 交易流水.xlsx --case-id case001 --db case001.db

# Step 2: 查看结构
excelcli inspect case001.db

# Step 3: 生成映射
excelcli map case001.db --out mapping.json

# Step 4: 标准化
excelcli normalize case001.db --mapping mapping.json

# Step 5: 分析
excelcli analyze fund case001.db

# Step 6: 筛选特定交易
excelcli transactions case001.db --account "622848123456" --min-amount 50000 --csv

# Step 7: 自定义查询
excelcli query case001.db --sql "SELECT account, COUNT(*) as cnt, SUM(amount) as total FROM bank_transactions GROUP BY account ORDER BY total DESC" --limit 50
```

### 涉税分析

```bash
# Step 1: 导入
excelcli import 发票数据.xlsx --case-id tax001 --db tax001.db

# Step 2: 涉税映射
excelcli tax map tax001.db --out tax_mapping.json

# Step 3: 标准化
excelcli tax normalize tax001.db --mapping tax_mapping.json

# Step 4: 风险分析
excelcli tax analyze tax001.db --top 20

# Step 5: 发票筛选
excelcli tax invoices tax001.db --taxpayer "某某公司" --min-amount 100000 --csv
```

## 五、通用技巧

| 场景 | 命令 |
|---|---|
| 查看帮助 | `excelcli --help` 或 `excelcli <命令> --help` |
| 查看版本 | `excelcli --version` |
| JSON 输出 | 几乎所有命令都支持 `--json`，方便程序化处理 |
| CSV 导出 | `query`、`transactions`、`tax invoices` 支持 `--csv`，方便导入其他工具 |
| SQL 文件 | `query --file analysis.sql` 可从文件读取复杂 SQL |
